Import of Html files into spreadsheet programs (e.g. Excel)

One way is to highlight the specific table and copy it. 
Thereafter paste it into the spreadsheet.
 
The other option is to open the Html file directly 
in the spreadsheet program.
For this purpose you need to use the path name of the respective file (example: Stats/AN13992.htm). 
This path is normally shown by your browser in the address window when you open an html file 
by clicking on it. In case of several files with the same code the data is in the file which 
includes 'body' in the name. If you open the files directly you have to adjust the column width 
of the first column to better view the table.
