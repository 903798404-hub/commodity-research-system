# Oil World 原始资料外置规则

## 当前布局

Oil World 授权原始 Excel、HTML、Stats 报表、图片、PDF、启动文件和历史导入脚本统一保存在 Git 仓库外。各发布期继续使用 `{raw_root}/{release}/` 结构，文件名和原有相对目录不变，不再为同一批资料维护 ZIP、日期归档或第二套近似目录。

程序按以下优先级解析 `raw_root`：

1. 环境变量 `OILWORLD_RAW_DATA_ROOT`；
2. 不进入 Git 的 `02_configs/local_paths.json`；
3. 仓库内 `01_原始资料` 旧布局兼容回退。

本机覆盖文件只包含路径，不得包含认证信息，格式为：

```json
{
  "OILWORLD_RAW_DATA_ROOT": "D:/data/OilWorld"
}
```

## 使用边界

- 新增原始 Excel、HTML、PDF、图片和附属介质只写入统一外部目录，不提交到 Git。
- 读取、工作簿重建、季度发布和核查脚本使用同一个路径解析入口，不在各脚本重复硬编码绝对路径。
- 发布期目录必须且只能包含一个与发布期匹配的主 Excel；原始文件只读使用，不由发布脚本覆盖。
- 正式发布快照、映射审计、源码、配置和测试继续保存在项目目录并按既有 Git 规则管理。
- 迁移、删除或去重前必须确认运行引用、逐文件哈希和恢复来源；不得因清理改变脚本依赖的相对目录结构。
