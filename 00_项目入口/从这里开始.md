# 从这里开始

这是农产品研究 Agent 项目。

## 每日国内基差面板

正式原始数据源：

`01_data/manual/榨利表/油脂油料价格.sql` 中的 `basis_price` 表

然后只需运行：

```powershell
python 04_scripts/run_local_dashboard.py
```

脚本会先更新正式基差数据库，再显示数据摘要并启动面板。即使只是重新打开页面，也建议使用该命令，避免读取旧数据。

历史 Excel `01_data/manual/basis/国内现货基差.xlsx` 只作备份和人工核对，程序不会改写。

标准化输出放在 `01_data/processed/basis_spread/`。

网页入口放在 `05_apps/`。

核心代码放在 `03_src/agri_research_agent/`。

## Streamlit 面板

正式启动命令：

```powershell
streamlit run 05_apps/streamlit_app.py
```

也可以使用启动辅助脚本：

```powershell
python 04_scripts/run_streamlit.py
```

项目只使用 `05_apps/streamlit_app.py` 作为正式面板入口。
