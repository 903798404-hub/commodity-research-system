# releases 目录说明

本目录由 `09_deploy/spread_release/create_release_manifest.py` 按 Release ID 创建不可覆盖的发布子目录。真实发布目录包含 `release.json`、`release.env` 和 `checksums.sha256`；正式切换成功后另写 `deployment_result.json`。

真实发布事实只能在对应 Git 提交的镜像已经构建后生成，因此不能再提交进它所标识的同一 Git 提交，否则会形成提交与镜像身份循环。每个真实 Release 子目录在本机或服务器仓库内持久保留，但由 `.gitignore` 排除；本说明文件和发布契约工具由 Git 管理。

这里不得存放 `.env`、密码、Token、API Key、私钥、服务器地址或业务数据文件。本次本地实现不生成任何真实发布清单；真实清单只能在候选镜像、Image ID、OCI revision、镜像内版本文件和数据基线全部验证后生成。
