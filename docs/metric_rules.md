# 商品页面指标规则

所有表格按市场年度展示。数量指标应用 README 中的单位转换规则；库存/总使用比按百分比展示，保留一位小数。

## 市场年度口径说明

页面的“市场年度口径说明”统一展示国家或地区、品种范围和市场年度三列，不展示固定年份示例。棕榈油中，Malaysia、Indonesia 和 G2 均采用 10 月—次年 9 月口径；G2 表示马来西亚与印度尼西亚棕榈油合计。

## 扩展规则

其他油脂和粕类页面沿用相应 Soybean 页面模板，并按商品名关联其上游油籽。属性名称必须以 USDA 的 `Attribute_Description` 为准；缺失值应明确显示为缺失，而非填充为零。
