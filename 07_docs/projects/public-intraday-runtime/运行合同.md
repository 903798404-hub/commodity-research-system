# Shared Intraday Production Runtime v2

本项目只提供 `shared-intraday` 的独立 OCI runtime wiring。Production 与 Preview 必须使用不同
runtime identity、宿主根目录和授权；Preview 不得取得 production grant 或 production rw mount。

容器以只读 root filesystem 和数字非 root 用户运行。`/runtime` 保存只读 marker，`inputs` 只读，
`snapshots` 是唯一业务可写 mount。Tankan 凭据只通过 Compose file-backed secret
挂载到 `/run/secrets/tankan.env`；candidate validation 不注入、不读取该 secret，也没有网络。
镜像中的 production trust 配置与全部 Python 源文件均属于 manifest source binding；Dockerfile
不得复制 binding 之外的仓库文件。

`readonly-preflight` 只验证 manifest、marker、OCI execution identity 与固定路径；FORMAL 使用只读
context 并另行验证 production grant，不取得业务写入口。它不读取带日期请求、不访问 provider、不写
runtime。实际 capture 必须由人工显式提供
`business-date`、`AM|PM`、位于 `/runtime/inputs` 的 request 与 calendar，并由 host 注入匹配的
production grant。不存在镜像内默认日期、当前日期 fallback 或固定历史日期。

`AM_PM_AUTO_EXECUTION=NO`；`INTRADAY_FULL_DAILY_DEPENDENCY=NONE`。本项目不加入 cron、Scheduled
Task、FULL DAILY、Production Wrapper、Provider Preflight、Daily Summary 或 Notification，不重新
capture 历史 AM/PM，不修改旧 SEALED。`REAL_AM_TEMPORAL_ACCEPTANCE=DEFERRED`；
`REAL_PM_TEMPORAL_ACCEPTANCE=DEFERRED`。

候选验证只能证明无 `.git` 镜像中的初始化、身份、依赖、路径、权限和拒绝性探针。真实 Tankan
连通性、secret 文件权限、actual deployment source、真实 Image ID、rendered Compose 与 mounts
必须由 pre-release/deployment host revalidation 绑定；候选 PASS 不等于 Production Approval。
