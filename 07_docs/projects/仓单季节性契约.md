# 仓单季节性契约

本模块在主工作台“价差动态”内部增加“仓单季节性”研究视图。首期品种为现有国内品种 M、Y、P、RM、OI、SR，使用自然年、月日对齐，分别展示仓单总量和源每日增减。仓单不等于产业库存。

数据来源为用户此前使用的 Tushare 兼容网关或 Tushare Pro 的 `fut_wsr`，官方字段文档为 https://tushare.pro/wctapi/documents/140.md。认证来自 `TUSHARE_TOKEN`，目标接口来自 `TUSHARE_API_URL`（默认 `https://api.tushare.pro`）；不得在源码、输出、日志或 Git 中保存凭据。网络获取只能在独立数据准备入口执行，页面不调用外网。

字段保留完整 `trade_date,symbol,fut_name,warehouse,wh_id,pre_vol,vol,vol_chg,area,year,grade,brand,place,pd,is_ct,unit,exchange`。日期严格解析 YYYYMMDD，原始单位必填。业务键为日期、品种、仓库、仓库编号、地区、年度、等级、品牌、产地、升贴水、折算标识、单位、交易所。完全相同的重复观测去重；同键冲突停止。不同品牌或年度的同仓库记录不能按仓库名称去重。

同日同品种仅允许一种单位；跨日单位变化分开绘图，不拼接，不自动换算吨数。仅汇总仓库/厂库明细，忽略小计；存在唯一总计时使用源总计，同时与完整明细核对。总计与明细不重复累计，多个总计或核对不一致停止。`vol/pre_vol/vol_chg` 各自有任一分项缺失时，各自汇总为空。未返回日报的日期为缺测，不生成零。源明确的零保留。每日增减取源 `vol_chg`，不按跨缺测日期的总量差反推。负仓单量保留原始值，将对应日度汇总置空并标记 `invalid_component`；禁止取绝对值或忽略该仓库强行求和。状态为 `actual`、`missing_component` 或 `invalid_component`。

请求按14个自然日分段，响应达到1000条上限时二分为不重叠日期段，单日仍触顶则停止。raw 保存每次请求的目标、日期、字段、记录和时间以及 SHA256，不保存 Token 或服务端消息。重新执行可校验复用已获取窗口，失败不切换候选指针。

路径：`01_data/raw/warehouse_receipts/<run>/` 保存原始记录；`01_data/candidates/warehouse_receipts/<run>/snapshots/<sha>/` 保存不可变 raw.csv、daily.csv、manifest.json；候选 `current.json` 原子切换。稳定目录为 `01_data/processed/warehouse_receipts`，发布由独立数据流程核验，准备入口不写稳定或生产数据。SHA 清单绑定原始和日表，更新/发布前完整验证哈希、条数、从原始记录重算日总量。页面只读取已校验的紧凑日度表，复核日表哈希、日度键/数值/缺失状态及指针不变；不在页面中重放全部仓库原始记录。

页面优先读取明确的 `WAREHOUSE_RECEIPTS_ROOT`；否则读取 `SPREAD_DATA_ROOT/processed/warehouse_receipts`，无 SPREAD_DATA_ROOT 时使用本项目 `01_data`。生产数据挂在既有只读 `/runtime/01_data`，容器 `/app/01_data` 由既有机制链接到该目录；网页容器不增加RW挂载或migration；自动取数由下述独立定时服务执行。代码打包与真实数据发布是两件事。

自然年曲线以闰年2000为横轴锚点，2月29日不平移其他日期。缺失交易日用本项目已使用的 AKShare 内置中国期货交易日历显式断线，无覆盖时提示。对比年用共享红色和线宽3.4，历史固定年份色、线宽2、透明度0.55。页面仅展示各年份的实测曲线，不计算或显示均值，也不提供均值开关。默认选2022年起已有数据，更早记录可在独立历史获取后选取。

自动更新采用独立 Linux systemd oneshot 服务：北京时间每天17:30执行，18:30、20:00仅在当日未成功或仍有待补品种时重试，Persistent=true补偿漏跑。交易日来自同一接口的DCE trade_cal，区间日期、交易所、开闭市标记逐项核验；旧历史日历以既有AKShare内置日历为bootstrap，更新窗口用实际接口日历覆盖，支持跨年。

更新入口回查六品种最新日期最小值之前14个自然日，并补齐至运行当天。返回的完整品种×日期替换该日仓库明细，以接收修订或已注销仓库；未返回的日期/品种保留旧观测，不推定零或删除历史。原接口JSON保留，标准表年度/升贴水及完整键排序规范化，响应行序变动不产生伪修订。单次请求最多三次重试；源数据未齐标记WAITING_FOR_SOURCE，全部最近交易日已齐才允许跳过当日后续重试。失败标记FAILED且保留先前快照。

服务器控制器仅从root-owned、clean、精确Approved Commit/Tree源码执行，固定不可变Image ID和数据盘UUID。凭据存放在Git外root0600配置目录；采集器非root、只读rootfs、无额外权限、资源受限，仅只读挂载基线，RW仅落独立临时output。采集器使用固定镜像内入口，执行完整原始记录重放和语义核验后退出。主机在独占锁下复核文件清单、内容身份、旧指针CAS，保留旧不可变snapshot并原子切换当前指针；不写其他模块，不替换网页容器。无变化仅追加小状态记录，不复制整份历史；发布成功后只清理本次已校验的重复staging三文件，正式快照和源JSON保留。

页面首次打开无需重算原始仓库历史；明细表、CSV下载和数据口径在用户展开时才生成。网页访问不触发取数。显示最近检查北京时间、更新/无变化/等待源数据/失败状态，每张卡仍写实际观测日期。

代码、历史数据、定时服务按统一发布任务分别核验；回滚只切换经验证指针，旧历史不改。生产授权、恢复来源及发布事实另行核验，不能由本契约推定。
