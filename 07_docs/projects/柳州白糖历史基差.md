# 白糖现货与基差独立页面

市场行情导航中的“白糖基差”为独立页面，包含柳州现货、01/05/09 合约季节基差、主力季节基差与三地长周期主力基差。国内现货页保留基差、一口价、批发价差三个标签；两页分别读取数据，白糖不依赖油脂粕类 Formal Public Basis Current 的可用性。

上述页面的日常图表使用 Plotly，支持悬停查看实际日期、价格及合约、图例开关、缩放和图片导出；三地长周期图另有日期范围滑块。空值与超过五个交易日的缺口不连接，零基差为有效值。静态绘图函数仅保留用于导出与兼容验证。

既有后台预计算在 `MARKET_DATA_PRECOMPUTE_MODE=record` 时继续走 PNG 导出入口并保留原缓存契约；普通网页显示不生成或写入 PNG 缓存。白糖历史仅在进入独立页面时读取，国内现货只绘制当前标签。

现货使用钢联“白糖：现货价：柳州（日）”，指标描述为当地贸易商报价平均值。另一条一级糖含税车板价保留在原始历史库中，不与主序列拼接。单位为元/吨。

基差为同一业务日的柳州现货减 SR 交割合约未复权收盘价。固定月使用 01、05、09，保留完整代码与交割年；主力辅助序列依据来源的实际 `SR.ZCE` 映射，历史 03、07 月主力使用对应真实合约。缺失保持 NULL，周末现货不配前一日期货。

现货和主力按自然年比较。固定交割月的窗口为上年交割月后一月起，至该合约交割月；图例为 `2026/27` 等周期。颜色按周期起始年匹配现有国内基差模板，例如 2024 蓝、2025 橙、2026 红。页面展示完整日数据，支持历史年份选择和日数据下载。

## 快照准备与读取

一次性准备入口为 `04_scripts/prepare_domestic_sugar_history.py`，必须显式指定已审核的来源目录和本项目 `01_data/candidates/domestic_sugar_history` 下的独立候选目录。它核对来源核验记录中的数据库 SHA256，再校验重复键、NULL、精确同日行情、主力映射及基差公式，然后构建独立副本。不同快照必须使用新的候选目录。

快照结构为 `current.json` 和 `snapshots/<数据库SHA256>/history.sqlite3, manifest.json`。清单绑定币种、单位、现货序列、收盘字段、来源身份和各表条数。页面拒绝不一致的指针、清单或数据库；白糖校验失败只暂停白糖图表，不更改油脂粕类数据。

页面默认读取 `01_data/processed/domestic_sugar_history`；本地验收可以显式指定进程环境变量 `DOMESTIC_SUGAR_HISTORY_ROOT` 指向本次独立候选。源文件、候选数据和清单不进入普通 Git 提交。`05_apps/domestic_sugar_basis_preview.py` 用于本机查看同一页面实现。

现货后续由用户每天提供报价截图后核验更新，不启动定时抓取。核对截图业务日期、地区、具体报价项目和单位，保留截图证据；若其报价口径与当地贸易商报价平均值不同，单独保存，不能直接拼接。未提供或未核验日期不生成价格。正式接入运行数据时按独立的数据流程传输与验证，不得夹带替换油脂粕类 Current。

柳州页同时读取已校验的较新三地快照，构造只读展示视图，避免三地数据已有新报价而柳州页仍停在旧捕获日期。三地快照必须绑定当前柳州历史身份，重叠非空现货、实际主力代码及收盘价必须一致，冲突时保留旧柳州视图并显示实际日期。展示合并不改写任一来源指针或文件，明细保留各来源单元格与 SHA256。

较新三地快照的实际主力收盘价，仅可补充相同日期、相同具体合约的固定月基差；不能据此生成其他月份行情。顶部指标卡统一对应最新有效现货日期，当日缺少相应合约收盘价显示空值并注明缺失日期，不将更早基差标成最新值。

既有 `sugar_basis` 人工监控依赖改为关联独立页面，读取相同的只读合并视图，分别记录有效现货、主力与 01/05/09 基差的实际日期；空值记录不代表已更新，较新的现货不能覆盖某个合约缺价或日期滞后。依赖标识、人工模式、原监测窗口及全部服务和定时器保持原样。

## 可选三地长周期图

柳州季节图下方按真实日期排列的主力基差图，同时显示柳州、昆明、乌鲁木齐。默认从 2025 年 1 月 1 日开始，开始与结束日期可以调整到全部来源历史；默认起点限制在来源日期范围内。柳州指标卡、01/05/09 交割合约季节图和主力季节图的数据口径不变，较新同口径快照按上节规则合并显示。

三地均采用钢联导出表 `导出数据` B/C/D 列的“当地贸易商报价平均值”，减去同一日期、同一实际 SR 主力合约的未复权收盘价，单位元/吨。主力按来源映射选择，包括历史实际出现的 03/07 月合约；不使用复权连续价格，不将各年 09 合约拼成长周期主力序列。换月跳变保留。缺少现货或同日期货时留空，周末不匹配前一交易日。明细保留实际合约代码、原表现货单元格并可下载。

图右侧标注所选日期范围内各地最后一个有效基差，颜色与曲线一致，用引线连接实际日期的末端点，并错开相近标签。图上注明最新有效日期；某地区最后有效日期更早时，在该地区标签下单独注明日期，不将旧值标为今日数据。

独立数据默认读取 `01_data/processed/domestic_sugar_regional_history`，本地可通过进程环境变量 `DOMESTIC_SUGAR_REGIONAL_HISTORY_ROOT` 指定候选。未配置数据时不增加页面内容；新快照校验失败仅暂停这张图。数据格式为 `current.json` 与 `snapshots/<SHA256>/history.json`，内容身份绑定现货文件 SHA256、原表列口径、既有主力来源快照及可选补充行情 SHA256；基差由原始数值现场计算。

准备入口 `04_scripts/prepare_domestic_sugar_regional_history.py` 必须显式传入 `--spot-workbook`、`--spot-sha256`、`--main-history-root`、`--candidate-root`。候选只能位于本检出 `01_data/candidates/domestic_sugar_regional_history` 下。可选 `--main-extension` 和 `--extension-sha256` 必须同时指定，内容为原始 `fut_mapping` 与 `fut_daily` 返回记录，重叠历史不一致时拒绝替换。入口不联网、不发布、不修改输入或既有柳州快照，重复相同候选返回 NO_CHANGE，不同内容须使用新目录。每天人工补充现货截图后的录入与发布需走独立校验流程，本改动不启动定时更新。
