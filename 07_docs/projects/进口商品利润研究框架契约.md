# 进口商品利润研究框架契约

> 文档状态：当前项目唯一权威业务契约。定义现行大豆页面、数据和计算口径；部署身份以实际源码、镜像与受保护记录为准。

## 1. 项目范围

进口商品利润研究框架的首期实例是日度进口大豆盘面净榨利，接入现有工作台 `import_profit` 入口，使用 `soybean_margin` 包和 `soybean_margin_page.py`，不新增业务服务。通用框架的 `import_profit` 历史模块保留作为共享消费者和恢复来源；保留源码不授予旧入口执行权限。

加拿大菜籽与24度精炼棕油分别使用`canola_import_profit`和`palm_import_profit`独立入口及`commodity_import_margin`包；大豆入口和日度链保留。菜籽采用压榨模型，棕油采用直接进口利润模型。服务器读取验证正式身份；保存和当前取价需显式开启，不注册定时任务。

棕榈油使用直接进口利润模型，不得套用出粕率或出油率。

## 2. 参数与公式

产地为巴西、美湾、美西、阿根廷。四个产地默认参数相同：出粕率 0.795、出油率 0.19、换算系数 0.367437、关税率 0.03、增值税率 0.09、港杂费 50 元/吨、加工费 150 元/吨。

```text
美元成本 = (CBOT日度价格 + CNF升贴水) × 0.367437
完税成本 = 美元成本 × 汇率 × (1 + 关税率) × (1 + 增值税率)
盘面净榨利 = 豆粕盘面 × 0.795 + 豆油盘面 × 0.19 - 完税成本 - 港杂费 - 加工费
```

净榨利单位为元/吨。页面保留扣费后的净榨利口径，CBOT 未取得额外来源证据时只称日度价格，不称官方结算价。任一计算输入缺失时相关结果保持 NULL，不使用替代报价伪造结果。

加拿大菜籽 CNF 是美元/吨完整报价，不叠加 ICE 或其他期货价格。确认的研究参数为出粕率57.3%、出油率41.7%、有效关税字段14.9%、增值税9%、港杂50元/吨、加工220元/吨。完税成本 = CNF × 汇率 × 1.149 × 1.09；盘面净榨利 = RM × 0.573 + OI × 0.417 − 完税成本 − 50 − 220。

24度精炼棕油 CNF 同为美元/吨完整报价，关税字段9%、增值税9%、港杂80元/吨。完税成本 = CNF × 汇率 × 1.09 × 1.09 + 80；进口利润 = P − 完税成本，不计压榨出品率或加工费。上述参数是用户截图确认的研究口径，不构成对所有历史时期税收适用性的认定；快照保留参数及版本，后续参数调整须保留旧版本解释器。

## 3. 手工 CNF

CNF 是当日主表唯一可编辑数据，单位美分/蒲式耳。数字 `0` 是有效平水报价，空值是真实 NULL；不向前/向后填充、不跨日期继承、不按邻近船期插值。

逻辑业务键为 `business_date`、`commodity`、`origin`、`shipment_year`、`shipment_month`；现行独立大豆 SQLite 中 commodity 固定为 soybean，实际主键为其他四列。允许补录或修改历史日期；同一业务日和产地按版本 compare-and-swap 校验并发保存，不允许过期版本覆盖较新修改。

新记录写入 `import-profit/operational/cnf/cnf.sqlite3`；旧 `manual_cnf_quotes.parquet` 只读读取，不迁移、不覆盖。正式保存必须验证 application-service credential 和正式运行上下文，本地预览标志不能绕过正式身份。

## 4. 行情读取与日期

2026-10-08 起，现行页面读取独立日度 API 快照；此前保留历史和 Public Current 原口径。日度主表及历史继续读取已发布输入；新增CNF提交时行情仅作为独立参考结果，不写入日度快照、Public Current或历史曲线。

服务器网页显式启用`SOYBEAN_MARGIN_SUBMIT_QUOTES=1`后，确认保存CNF会调用`soybean_margin.reference.submit`：按现有compare-and-swap规则原子保存CNF、新版本及不可变提交身份，再立即采集最新可用内外盘报价。默认未启用时保持原保存行为；普通输入编辑、预览和页面刷新不联网。历史业务日CNF补录只保存输入，不把今天的行情附到过去日期。

国内盘面读取新浪`hq.sinajs.cn`的明确M/Y月份`current_price`对应字段，保留全部原始字段、日期、时间和响应SHA；允许同日最多60分钟延迟，未来、旧日、缺价及未上市合约保持NULL。美豆读取东方财富国际期货逐月`p`报价，按实际分页大小读取完整清单并核对数量及代码唯一性；保留所需月份原始记录、分页SHA和`utime`/`spsj`字段，不把未经确认的时间字段称为成交时间，也不保证严格同步或固定延迟。来源时间未知时明确显示`timestamp_unknown`，仅供提交时参考。汇率沿用下述CFETS在岸即期与同日期限曲线规则，禁止替换为CNH或供应商人民币换算价。

各来源并行请求，逐项保存请求时间、返回时间、合约、单位、报价时间或未知状态；单源失败不覆盖其他有效输入，不使用旧快照、邻月、主连或昨收补齐。每次提交的参考榨利绑定CNF产地、业务日期及版本，沿用当前船期映射、公式和参数。旧请求晚返回只能完成其原版本记录，不覆盖新版本；取数失败仍保留已保存CNF。新增`quote_submissions`表位于原有授权的`cnf.sqlite3`内，保留CNF修订快照、结果JSON及SHA，单条最多256KiB；复用现有工作台服务身份和SQLite写入目录，不增设挂载或生产写入权限。旧镜像可忽略新增表，历史数据不被改写。

## 8. 巴西与泰国白糖进口利润

`白糖进口利润`入口使用独立`sugar_import_profit`模块，展示与巴西大豆盘面榨利相同的红色表头、12个月船期表及每行3张月份季节图。新入口只使用本人逐日保存的报价与测算，不再读取、展示或依赖钢联历史利润；原始历史文件不删除、不改写。行情或升贴水缺失时留空，平水0与空值分别保存，不跨日期继承升贴水或行情。海运费按8.4节的最近报价沿用假设处理。固定参数可沿用该产地此前最近已存的新公式参数，但不继承未来日期或其他产地参数。

### 8.1 新公式与参数

2026-10-26用户提供计算参考图，新公式版本为`sugar-monthly/2`。采用第一张图右侧明确写出的公式，未采用左侧数值框不一致的结果：

- FOB（美元/吨）=（ICE原糖价＋FOB升贴水）×22.046；
- 保险（美元/吨）= FOB×保险费率；
- CIF（元/吨）= [FOB×(1＋保险费率)＋海运费]×USD/CNY；
- 加工后成本 = CIF×(1＋关税)×(1＋增值税)×(1＋损耗)×(1＋银行手续费率)×(1＋外贸代理费率)×旋光度系数＋利息劳务费＋加工及国内运杂费＋其他费用；
- 配额内／外进口利润 = 对应郑糖具体合约价－各自加工后成本。

默认研究参数：保险费率0.004616、银行手续费率0.00125、代理费率0.01、利息劳务费25元/吨、增值税13%、损耗2%、旋光度1.04、加工及国内运杂费500元/吨、配额内关税15%、配额外50%。这些参数来自用户参考图，并非所有日期或合同适用的实际费率。第二张图指出的CIF合同已含保险等情况需按实际合同修改参数，不能重复计费。参数在折叠区可修改，保存时完整快照化；旋光度只在税费及费用后乘一次，不预先放进FOB。选择实际损耗口径时以除以(1－损耗率)替代成本加成，页面明确标识选择。
