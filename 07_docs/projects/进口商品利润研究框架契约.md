# 进口商品利润研究框架契约

> 文档状态：当前项目唯一权威业务契约。定义现行大豆页面、数据和计算口径；部署身份以实际源码、镜像与受保护记录为准。

## 1. 项目范围

进口商品利润研究框架的首期实例是日度进口大豆盘面净榨利，接入现有工作台 `import_profit` 入口，使用 `soybean_margin` 包和 `soybean_margin_page.py`，不新增业务服务。通用框架的 `import_profit` 历史模块保留作为共享消费者和恢复来源；保留源码不授予旧入口执行权限。

后续菜籽可使用独立压榨计算器；棕榈油使用直接进口利润模型，不得套用出粕率或出油率。扩展必须明确品种、来源和映射，不由本契约自动启用。

## 2. 参数与公式

产地为巴西、美湾、美西、阿根廷。四个产地默认参数相同：出粕率 0.795、出油率 0.19、换算系数 0.367437、关税率 0.03、增值税率 0.09、港杂费 50 元/吨、加工费 150 元/吨。

```text
美元成本 = (CBOT日度价格 + CNF升贴水) × 0.367437
完税成本 = 美元成本 × 汇率 × (1 + 关税率) × (1 + 增值税率)
盘面净榨利 = 豆粕盘面 × 0.795 + 豆油盘面 × 0.19 - 完税成本 - 港杂费 - 加工费
```

净榨利单位为元/吨。页面保留扣费后的净榨利口径，CBOT 未取得额外来源证据时只称日度价格，不称官方结算价。任一计算输入缺失时相关结果保持 NULL，不使用替代报价伪造结果。

## 3. 手工 CNF

CNF 是当日主表唯一可编辑数据，单位美分/蒲式耳。数字 `0` 是有效平水报价，空值是真实 NULL；不向前/向后填充、不跨日期继承、不按邻近船期插值。

逻辑业务键为 `business_date`、`commodity`、`origin`、`shipment_year`、`shipment_month`；现行独立大豆 SQLite 中 commodity 固定为 soybean，实际主键为其他四列。允许补录或修改历史日期；同一业务日和产地按版本 compare-and-swap 校验并发保存，不允许过期版本覆盖较新修改。

新记录写入 `import-profit/operational/cnf/cnf.sqlite3`；旧 `manual_cnf_quotes.parquet` 只读读取，不迁移、不覆盖。正式保存必须验证 application-service credential 和正式运行上下文，本地预览标志不能绕过正式身份。

## 4. 行情读取与日期

2026-10-08 起，现行页面读取独立日度 API 快照；此前保留历史和 Public Current 原口径。页面不连接供应商、不采集，CNF 预览和保存不触发行情更新。

- CBOT 使用 Databento `GLBX.MDP3`、具体 ZS 月份合约、`ohlcv-1m` 的 08:59–09:00 北京时间分钟收盘价，单位美分/蒲式耳。Historical 尚不能访问当日窗口时留 NULL，不自动购买 Live。Historical 可用后只补当日 CBOT，不能用当前汇率或国内价格替换过去日期。
  当日美豆使用用户提供截图，经确认业务日期和合约年份后录入“最新”报价（美分/蒲式耳），归档原图SHA-256、完整合约、收到时间及所有修订。报价时间未提供时留空并提示时间未知，不宣称严格09:00。新截图替换该日原人工报价；Databento历史回填只补未提供合约，再次采集保留人工输入。未映射的月份仍保留在凭证中；不自动读取TradingView。
- 国内使用 AkShare `futures_zh_spot` 对应新浪具体 M/Y 合约的 `current_price`。新浪新增深度字段时只向 AkShare 传入原28字段，原始合约、日期和时间另存验证。未上市或无报价的 M2801/Y2801 等留 NULL，不能用主连、近月、昨收或结算价替代。
- 汇率使用 AkShare 所指向的 CFETS 公开即期和掉期报价，限定在岸 `USD/CNY`。即期使用买卖报价均值；远期全价 = 同日即期均值 + 同日掉期点买卖均值 / 10000；不是人民币中间价或 CNH。
  距业务月1–2个月的船期使用即期，3个月及以上使用对应船期期限远期；1M/3M/6M/9M/12M 曲线中非标准期限只在相邻有效远期之间线性内插，留存期限和插值标记，禁止跨日和外推。

独立采集入口为 `04_scripts/import_profit/capture_soybean_api.py`，计划09:35运行，允许同日09:35–15:00补采且记录实际时间；交易日以 AkShare/Sina 交易日历为前置条件，日历覆盖不足停止，不从报价是否存在推断交易日。
国内原始报价时间、CFETS页面发布时间必须同日、不在未来、距读取时刻不超过5分钟；页面发布时间不冒充每笔独立成交时间。按来源独立失败并保留空值和错误码，页面显示实际采集时间、CBOT状态和缺失原因。
读路径为既有 snapshots 挂载下的 `soybean-api`，写路径为对应 capture-snapshots 挂载下的 `soybean-api`，须验证工作台服务上下文，不能写 history、Public Current 或 CNF。
每日快照按内容SHA保存不可变修订，经文件锁和原子指针发布；读取验证单位、币种、合约、日期和文件身份。单份256KiB，集合最多4096日及64MiB，超限拒绝。
凭据从进程环境变量或仓库外独立文件读取，不进入快照、Git、页面或异常日志。生产定时任务和数据写入需单独完成生产验收和授权，本地联通不等同生产启用。

页面读取先验证 Current 指针、清单、完整文件身份和完整 Parquet schema，再仅扫描
CBOT SOYBEAN、国内成功 M/Y 记录及计算必需字段；不得先将整个公共行情库转换成 pandas。
扫描分批、禁用并行预取；每张输入视图上限 100 万行和 64 MiB Arrow 数据，超限报错，
不截断、不退回全量读取。缓存各最多保留两个版本，不缓存按日期展开的整份历史合并结果。
刷新仅失效当前行情版本的缓存键，不清除其他会话和版本；不触发数据更新或代码部署。

CBOT 和国内 M/Y 按同一业务日期和明确完整合约匹配。缺失值保留 NULL，不得使用上一业务日行情回填，不得回退到前一日期。汇率直接使用可用目标期限；缺失时只允许同一 `business_date` 的相邻有效期限内插，保存 `fx_is_interpolated`、`fx_lower_tenor`、`fx_upper_tenor`，禁止跨日期和期限外推。

展示按 `Asia/Shanghai` 时区下的周一至周五组织业务日。页面合并已发布行情日期、历史日期和选定日期，不自行生成不存在的市场价格；中国法定节假日即使落在周一至周五也保留日期行。独立采集须验证交易日历，页面不启动采集。

用户自己的 Tankan/Lutou 数据库全量更新暂不可用。后续须先恢复并验证数据更新链、发布和同步，再让页面读取新 Current；没有新版本时如实显示当前数据日期。FULL DAILY 与代码发布分开授权。每日 SQL 数据及其运行结果不得提交 Git。

## 6. 页面、历史和图表

日表采用同事页面样式，历史季节图沿用用户原有样式和坐标格式。图表只保留 12 个船期月的大豆盘面净榨利，保留历史 CNF 表和历史净榨利表；不展示 CNF 报价图、到港完税成本图或“中国进口大豆历史完税成本 · 巴西”表。

历史季节图保留原始已发布净榨利观测值、12 个月周期。相邻真实有效报价间隔不超过 10 个日历日时连线，较长缺口留白；连线不生成中间价格，也不改写原始数据。修改历史 CNF 时仅对应业务键重算，未修改键的原历史净榨利保持不变。

## 7. 发布、回滚和旧方案

按根规范完成 required CI、main 审查、独立候选机器及业务验收、同一 Image ID 正式切换和最终验收。新 SQLite 属于独立新增状态，旧镜像回滚无需反向迁移，保留文件供再次升级读取；不能清理共享依赖、正式数据、凭据或唯一恢复来源。

已有用户认可的业务边界是一次性批准，不构成每次 bug fix 的审批；main 接纳和生产发布仍执行根规范的适用审查和授权。

旧 AM/PM、08:30 夜盘冻结、SQL 汇率和旧 CNF/成本图表方案见[历史契约](../archive/2026-10-05-大豆旧AM-PM契约.md)。这些规则仅说明历史兼容源码与数据语义，不能要求现行页面启用采集、夜盘切换或旧图表；恢复旧链必须单独明确任务范围并验证。
