# 巴西大豆种植与生长

## 范围与页面

在既有 spread-dashboard 周度跟踪增加巴西大豆入口。播种、收割展示历史文件的全国汇总及12州；
全国汇总沿用来源，禁止重新加权或把12州简单平均当全国。现代 CONAB 汇总为覆盖约96%种植面积的12州，页面注明覆盖口径。
生长阶段只展示全国数据，不随州选择改变。第一版不开发销售、出口或省级优良率，不由进度自动判断单产或价格方向。

按作物季 YYYY/YYYY+1 分组；9月至次年8月为同一季节轴，12月开始收割仍属于原作物季。
默认当前作物季，不能用旧季数据冒充当前季。播种、收割图同时并排展示，窄屏上下排列，约300像素高。
全国生长阶段在下方展示分布比较表及可选阶段的历史曲线；阶段占比不是累计完成率，也不是优良率。
默认历史自2022/2023起，另保留上一季；当前季曲线最后绘制、红色突出，引用 shared/chart_style 的固定历史色、透明度及灰色均值线。
较均值用有符号百分点、红蓝底色突出，正负仅表示高低。

## 来源与历史导入

官方来源为 [CONAB Progresso de Safra](https://www.gov.br/conab/pt-br/atuacao/informacoes-agropecuarias/safras/progresso-de-safra)。
历史为用户《巴西种植生长进度.xlsm》，只读、不执行宏、不保存回原文件。

| 原始表 | 日期 | 数值 | 单位 |
|---|---|---|---|
| 巴西种植 | B；A作物季 | C:N十二州，O全国汇总 | 已为百分数，乘1 |
| 巴西收割 | C（表头虽写Harvest (%)，实际为日期）；A作物季 | D:O十二州，P全国汇总 | 小数比例，乘100 |
| 巴西大豆作物进度作图 | C；A作物季 | D:I全国原始阶段 | 小数比例，乘100 |

只读左侧原数据；不读透视月度求和、K:S累计公式、面积/单产/总产或旧表的州级0/1条件标志。
阶段中文为出苗、营养生长、开花、籽粒灌浆、成熟、收割；保留葡语字段定位。
空值/Excel错误/公式不能转成零，阶段不强制合计100、不截断超额合计、不自动构造累计阶段。
发现原始单位混用时，记录具体单元格与原值，未经官方同日来源核实的值隔离，不根据数值大小猜测换算。
已知原文件2024/2025播种首行的MT、PR、全国存在疑似比例混用，默认隔离这三个点并在导入说明列出；其余历史不删除。
历史日期为 workbook_date，发布日期未经逐期核实留空。更新分别保存实际统计截止日、发布日期、抓取时间及文件SHA；标题日期不能替代单元格截止日。
新版生长文件可能只有嵌入图片；只能从归档的图表人工核对阶段数值并通过校验，不假装存在可解析的数值单元格。

## 数据与同期对比

独立UTF-8 JSON schema=brazil-soy-progress/1。唯一键为作物季+地区+指标+日期。
每条保留0—100有限数值、官方URL、原始文件SHA、原始单元格/图表定位、日期依据、发布日期及抓取时间。
原始阶段允许不完整；若可用阶段合计偏离100%，输出审计说明，禁止据此认定缺失项为零。

去年及前五季各取相同季节月日及此前7天内最近记录；不取未来观测、不插值、不过期延续。
闰日映射到非闰年2月28日；均值不含所选季，只使用有效样本并显示n/5。
现代报告直接提供的上季同期值和官方五年均值另存 reference 字段，不伪造对应年份的观测。
表格优先使用同一报告同一截止日的官方参考值，并明确“官方”；不存在时使用历史记录计算并注明样本数。
图表历史均值始终按前五季观测计算；官方参考值不是可重建的完整均值曲线。
