# 泰国甘蔗天气

## 已授权范围

2026-10-21 用户要求按棕榈油天气的方式，在主工作台内直接呈现泰国甘蔗天气，后台独立自动更新，核实产区和面积，不影响现有模块。本扩展使用主站原生 Streamlit 页面，无 iframe、独立页面服务、端口或前端容器。既有棕油、广西、云南和 Public Weather Current 的读写链均不变。

## 面积和地区

- OCSB 原始统计，经 OAE《Agricultural Statistics of Thailand 2025》表1.17第41—42页（PDF第68—69页）发布。原件 `https://oae.go.th/uploads/files/2026/04/02/db0b6b4ca1f024ea.pdf`，SHA-256 `a4492bc95a2f2059d1524f2025cd82db066dd135476ac2f9661823558def207e`。序言2026年3月，NABC网页2026年6月发布；网页发布日期与原件序言日期分别保留。
- 固定参考年度2025：工业甘蔗 **收获面积** 9,628,085莱，47个省相加严格等于全国合计。1莱=0.16公顷=2.4亩。2026列标 `f`，为预测；不用于权重。不将收获面积改称播种或种植面积，也不混入OCSB全部种植面积。
- 首版选择面积最大的16省，合计7,476,274莱，占全国77.6506854686%。其余31省的面积保留在完整表中；不虚构天气、不给零值、不把16省重归一化到100%。
- 页面每省百分比=该省面积/全国9,628,085莱，作为重要性标签。本版没有全国加权天气指数。
- 点位为16个已留存甘蔗种植依据的县域内地理代表点；GISTDA县级边界 `L05_Amphoe_GISTDA_50k`，基于0.001度简化几何的中纬线最长内部段中点。种植依据和边界来源逐点登记在JSON配置；一些地方依据较旧，年份保留，不能声称为2025遥感蔗田中心或全省田块面积积分。后续县级实际面积/蔗田分布需单独核实后才能升级省内加权。
- MAPSPAM 2020初步读取出现分布疑点，未用于本版点位、面积或任何天气计算；探索资料仅保留在Git外研究输出。

## 天气口径

- Open-Meteo作为交付接口；2020-01-01起，降雨、气温历史明确指定 `ecmwf_ifs`，属于历史模式资料；土墒历史明确指定 `era5_land`，属于ERA5-Land再分析。两者均非站点/田间直接实测。固定历史基期2020—2024，各指标的当前年、历史年和基期均使用各自同一来源；土墒不得混入或接续旧IFS值。
- EC明确 `ecmwf_ifs025`，GFS明确 `gfs_global`；Single Runs接口请求同一个前一日12:00 UTC起报批次，展示当天开始14个完整泰国日。起报、请求、原始响应、下载时刻、SHA及返回坐标保留；不默认平均、不静默替代。
- 日界Asia/Bangkok（UTC+7）；累计降雨为 `(00:00, 次日00:00]` 24小时总和；最高气温为当日00—23时极值；0—100厘米土墒为三层（0—7、7—28、28—100厘米）按厚度7%、21%、72%加权的日平均体积含水率，乘100显示%。土墒只展示历史。
- 保留缺测和有效零；24个有效小时不足即留空。完整年度累计遇缺测后停止接续，不跨缺日接预报。五年均值要求同月日五个完整样本，不插值、不减少分母。2月29日不参与五年同日比较。
- ERA5-Land通常约5天发布延迟。日历槽位仍覆盖至降雨/气温的历史请求截止日，未发布和缺失土墒保留空值；清单单独记录每个产区土墒最后有效日及所有产区共同有效截止日。土墒尾部空值不阻止降雨、气温、EC/GFS每日独立更新；API失败或某产区完全无有效土墒时保留旧成功快照，不伪装成功。
- 页面采用自然年天气曲线，不能把自然年标签理解为糖厂榨季。

## 独立更新与存储

- CLI：`04_scripts/weather/update_thailand_sugarcane.py`。默认只生成候选；显式 `--publish` 校验后才切换 `current.json`。
- 默认独占根：`01_data/processed/thailand_sugarcane_weather/`；可用 `THAILAND_SUGARCANE_WEATHER_ROOT` 指定读写双方一致的路径。原始响应、失败响应、不可变release、manifest、pointer、最后尝试状态均在此目录；不写其他天气文件。沿用主站已有01_data只读挂载时不需新增挂载。
- 首次按年份建库；以后降雨/气温与土墒分别补新增日或已标记的缺口后缀，避免ERA5-Land延迟导致重拉其他指标。确切请求的原始响应按参数身份缓存。每次进程用操作系统文件锁互斥，崩溃自动释放；同一日期/预报批次的v2成功快照重复执行零网络、零发布。
- v2快照对全部土墒行强制 `source_model=era5_land`、`source_kind/data_type=reanalysis`。首次升级自动丢弃候选中的v1 IFS土墒并从2020年重算，沿用其余历史；旧release和原始响应完整保留。v1可供旧快照读取与回退，新页面不展示其IFS土墒，也不将其混入基期。
- 候选必须覆盖全部已配置地区和完整共同预测窗口；失败保留旧pointer。单个 `current.json` 原子切换，历史release保留供回退；不自动清理旧release或原始资料。
- systemd timer 默认继承现有天气每天北京时间08:30的约定。独立service使用与主站相同的确切已验收Application Image ID启动一次性数据容器，无端口、无其他业务挂载；根文件系统只读，仅本模块根目录和临时目录可写。无需在宿主另装Python依赖。模板中的镜像ID、UID/GID、持久数据盘路径必须在目标主机核验后替换；模板不是已安装服务。08:30为开始时间，不表示恰在08:30完成。
- 上游接口支持/许可、部署用户及主站读取目录需在正式服务器确认；不把模板存在或本地手动成功称为服务器自动更新成功。
