# 农产品持仓与资金情绪契约

> 当前项目专项契约。目标是直观观察多空倾向及其增强、减弱，不把持仓变化解释为现金流入流出。页面沿用主工作台“外资与重点席位”入口，旧矩阵页面被四板块选择器替换。

## 范围与数据来源

| 板块 | 国内 | 外盘 | 来源及边界 |
|---|---|---|---|
| 白糖 | SR品种及明确合约排名 | 糖11、伦敦白砂糖 | 郑商所、CFTC、ICE；各到期月份分类持仓汇总 |
| 菜籽 | RS、OI、RM | 加拿大菜籽、欧洲菜籽 | 郑商所、CFTC 135731、Euronext ECO/XMAT |
| 大豆 | M、Y全合约已披露持仓汇总；排除A和B | CBOT大豆、豆粕、豆油 | CFTC 005602/026603/007601；国内逐合约多空排名由登录浏览器读取东方财富后自行汇总 |
| 棕榈油 | P全合约已披露持仓汇总 | 马来西亚FCPO | 国内逐合约排名自行汇总；FCPO分类基金持仓仍缺来源，不补零 |

国内大商所官方入口曾返回HTTP 412及HTML脚本，未取得真实持仓ZIP。这不证明用户IP被封或必须购买权限。新浪响应按合约、日期、表头、连续排名及合计校验，与交易所交叉核对的覆盖有限；来源明确标注为新浪。其账户类型保持未区分。

用户已授权逐合约相加。02_configs/oilseed_positions.json的default_scopes保持M、Y、P品种；速览和国内选择器默认汇总。新增aggregation=disclosed_contracts_v1口径：各合约已披露多空排名按会员及账户分别合并，合并后重新排名并观察前20/前5；不是直接把各合约前20合计冒充品种前20。五家固定席位分别累加各合约已披露仓位，记录每侧上榜合约数。称为“全合约已披露持仓汇总”，不称完整席位持仓；某合约未上榜部分未知，某侧在所有合约均未出现时保持缺失，不补零。

浏览器采集保存当日来源列出的完整合约清单和每个合约的可见多空排名。导入逐一核验合约选择、标题、日期、连续排名和表内合计；少一个合约、少一侧或数据错误则整份文件不发布。访问完完整清单后，页面最近报告早于目标日期的合约明确排除并保存日期/原因，不混入当日汇总。大商所公开排名还受合约披露门槛限制，不声称覆盖所有上市月份或所有账户。

当前可用采集是用户授权的登录浏览器读取东方财富多空排名，自行计算汇总；不使用其净持仓页的估算值，也不提取登录凭据或调用受限接口。2026年10月8日直接浏览器核查确认大商所排名页可显示表格，但切换合约及批量下载仍有失败，程序请求曾返回412/HTML。不能据此宣称服务器自动采集已打通。统一联网更新入口仍记录M/Y/P自动采集pending，并保留已导入汇总；外盘和郑商所采集继续独立执行。没有任何有效汇总时显示待接入，单合约不回退为汇总。

Euronext只采纳明确标注FUTR/COMB的报告；较早缺少口径标签的历史不混入。期权合并持仓为Delta等价手，保留两位小数，分类之和不冒充总持仓。CFTC管理基金与Euronext投资基金分别观察，不跨市场合并手数。

## 页面与计算

- 默认显示资金情绪速览，净仓、多空方向、变化及实际截至日期；红表示向多，绿表示向空，不能单看颜色推断价格涨跌。
- 净持仓＝多仓－空仓。变化为相邻已保存同市场、同口径、同交易者分类及同合约/账户的差值；显示比较日期，间隔超过10天不计算变化。
- 国内前20/前5多空名单可以不同，变化包含名单更替；不是全市场净持仓。
- 五家固定席位为高盛/乾坤、摩根大通、永安、国泰君安、东证。未进入某侧排名保持缺失；只有五家两侧均完整才计算合计。默认郑商所代客，其余来源未明确账户类型时保留未区分。
- 合约汇总净变化按两份已保存汇总的净仓之差计算，不把席位表“增减”机械相加当作重新排名后前20净变化。来源、账户或聚合方法不同不混比；合约清单变化时净变化缺失并标明原因。五家合计有值只表示五家均有双侧已披露仓位，不保证未上榜部分完整。东方财富明确标注代客；旧新浪单合约仍保留未区分。
- 用户已移除前20与前5的双线对比、账户类型选择器和大标题下方说明；保持直接标注的五家曲线、变化柱状图、中文日期与简短情绪解释。
- 页面只读，不下载数据、不运行更新、不访问旧foreign_seat_positions.parquet。没有真实数据时展示缺口，不提供示例走势。快照损坏或属于其他板块时停止展示并报错。

## 存储、采集与数据交付

正式读取目录为PUBLIC_MARKET_DATA_RUNTIME_ROOT下processed/commodity_positions/<domain>，复用现有只读数据挂载，不新增容器、端口、挂载或写入权限。显式runtime配置下即使正式快照缺失，也不能回退到本地预览。未配置runtime的独立linked worktree允许读取原有隔离预览目录；主检出只读正式目录。

本地采集仍只允许linked worktree，且拒绝预览目录重定向。四板块统一入口：

```powershell
python 04_scripts/positions/update_positions.py --plan
python 04_scripts/positions/update_positions.py --markets domestic --days 14
python 04_scripts/positions/update_positions.py --markets foreign
python 04_scripts/positions/update_positions.py --domains soybean palm --markets domestic --days 14
python 04_scripts/positions/update_positions.py --export-only
python 04_scripts/oilseed_positions/import_contract_rankings.py --domain soybean --captures <已核验浏览器JSON>
python 04_scripts/oilseed_positions/import_contract_rankings.py --domain palm --captures <已核验浏览器JSON>
```

plan只显示计划，不联网或写文件。真实更新按板块顺序运行独立采集器，不写加拿大进出口、大豆榨利、CNF或其他板块的数据。退出码0表示各请求完成；2表示有失败或待确认来源（例如FCPO），成功来源仍发布且失败来源保留上一份已验证数据。统一入口有独占锁，不抢占遗留锁；已有来源采集器也保留快照发布锁。

浏览器JSON使用schema_version=1、acquisition=browser_dom、report_date及reports。每条报告保存contract、contracts完整列表、选中scope、可见date、两个含排名行和合计原文的tables、source_url及retrieved_at；不保存账号、Cookie或Token。导入器仅允许独立linked worktree且拒绝正式runtime环境变量。先验证全部输入，再用既有发布锁和不可变release原子提升本地指针；保留旧release。导入后页面只读已保存汇总，不会自动重新打开浏览器。

国内默认复核近期14个自然日的未保存报告，国内不超过120天；外盘读取最近两年，显式recheck-domestic可复核国内修订。原始响应保存URL、时间和SHA，修订按完整报告分区替换；不可变release和current原子指针保证页面不会读到半份报告。

export-only对所选板块的current、manifest、snapshot、所有引用raw进行SHA与板块身份校验，导出到独立06_outputs/commodity_positions/bundles目录；每份数据包包含独立bundle.json及全部文件SHA。导出不等于服务器数据发布。正式交付必须按现有受控数据写入身份执行，将各板块单独原子提升到正式读取目录，不覆盖其他模块；核对新数据盘实际挂载及UUID、容量、权限并保留上一个指针。尚未安装生产定时任务、尚未实现服务器自动提升入口，不得宣称自动更新已上线。

建议启用时间如下，全部为北京时间，尚未安装定时任务：

| 数据 | 官方发布规则 | 建议采集时间 |
|---|---|---|
| 国内SR/RS/OI/RM/M/Y/P | 交易日收盘后的排名；来源可能晚于收盘 | 交易日18:30首采、20:30补采 |
| CFTC糖11/加拿大菜籽/CBOT大豆、豆粕、豆油 | 通常周五15:30美国东部时间发布，反映周二持仓 | 周六06:00首采；假期延迟按官方实际发布补采 |
| ICE伦敦白砂糖 | 通常周五18:30伦敦时间发布，反映周二持仓 | 周六06:00首采 |
| Euronext欧洲菜籽 | 周三下午发布，反映上周五收盘持仓 | 周四07:00首采 |
| FCPO分类基金持仓 | 尚未确认可用来源 | 不启用，不生成虚假更新成功 |

官方依据：[CFTC release schedule](https://www.cftc.gov/MarketReports/CommitmentsofTraders/ReleaseSchedule/index.htm)、[ICE COT notes](https://www.theice.com/publicdocs/futures/CoT_Notes.pdf)、[Euronext CoT](https://live.euronext.com/en/products/commodities/commitments_of_traders)。美国、英国夏令时转换影响北京时间，以上建议采集时间覆盖正常冬夏令时发布；假日和延迟仍以实际报告为准。

上线时国内数据可按交易日收盘后安排采集和补采，外盘按报告发布频率安排。具体执行主机、时间、更新身份及数据包提升入口经实际配置核验后登记；页面刷新不是数据采集。新版代码发布也不自动发布数据。
