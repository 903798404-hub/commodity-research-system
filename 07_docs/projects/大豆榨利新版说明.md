# 大豆榨利使用说明

> 操作导航；业务口径以[进口商品利润研究框架契约](进口商品利润研究框架契约.md)为唯一权威来源。

在农产品研究工作台打开“大豆榨利”（`import_profit`），选择产地和业务日期后手工录入 CNF，再保存。并发版本冲突时重新加载最新值后再编辑。

其他行情读取已发布的 Public Current。数据更新完成发布及同步后，重新打开页面或点击“重新读取已更新行情”。以页面显示的数据日期判断新鲜度；页面打开和 CNF 保存不触发供应商采集。

全量更新恢复前继续使用已发布数据和手工 CNF。部署、数据更新、清理分别按[标准开发与生产发布规范](../03_标准开发与生产发布规范.md)执行，不因网页可访问就自动启动定时任务。
