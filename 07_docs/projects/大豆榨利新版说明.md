# 大豆榨利新版

现有工作台的 `import_profit` 入口改为 `soybean_margin_page.py`。日表使用 quanyong 页面样式，计算仍采用旧版净榨利口径：出粕率 79.5%、出油率 19%、关税 3%、增值税 9%、港杂费 50 元/吨、加工费 150 元/吨。仅保留盘面榨利季节图、历史 CNF 表和历史净榨利表。

CNF 由用户手工录入。新记录独立保存在运行目录 `import-profit/operational/cnf/cnf.sqlite3`；旧 `manual_cnf_quotes.parquet` 只读加载，不迁移、不覆盖。零报价有效，空值表示缺失；同一天、同产地的并发修改通过版本校验防止覆盖。正式写入须验证宿主注入的 application-service credential，不能使用本地预览标志绕过正式身份校验。

CBOT、汇率与国内豆粕/豆油从已经发布、同步到服务器的 Public Current 读取。页面不连接供应商数据库，不执行采集，不建立服务器定时任务。后续 FULL DAILY 恢复并完成发布、同步后，重新打开页面或点击“重新读取已更新行情”读取新版本。按同日、明确合约匹配；汇率仅允许同日两侧期限内插。缺失价格保留空值。

历史季节图沿用原始发布的净榨利观测值、12 个月周期和坐标格式。相邻有效报价不超过 10 个日历日时连线，较长缺口留白。人工修改历史 CNF 后，仅对应业务键的利润重算；其他旧历史值保持不变。

发布顺序：旧源码备份 → 分支检查和 required CI → 同一镜像的独立候选页面及业务验收 → 正式切换及验证 → 稳定后盘点、清理废弃资产。保留旧镜像、正式数据和新版 CNF 数据；回滚旧镜像无需反向迁移，新 SQLite 文件仍保留供再次升级读取。

旧入口已替换；旧模块源码暂保留作为回滚与共享依赖的恢复来源，正式验收完成后再评估退役范围。部署不执行 FULL DAILY，不改写 `01_data`、密钥、旧历史、日志和输出目录。
