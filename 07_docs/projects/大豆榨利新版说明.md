# 大豆榨利使用说明

> 操作导航；业务口径以[进口商品利润研究框架契约](进口商品利润研究框架契约.md)为唯一权威来源。

在农产品研究工作台打开“大豆榨利”（`import_profit`），选择产地和业务日期后手工录入 CNF，再保存。并发版本冲突时重新加载最新值后再编辑。

2026-10-08 起的行情读取独立快照：当天美豆由用户发送截图，确认合约年份和业务日期后读取“最新”报价；Databento Historical 后补缺失合约的分钟行情，保留用户已提供报价。国内具体 M/Y 合约走 AkShare/新浪；汇率走 CFETS在岸 USD/CNY 即期及远期曲线。远月无报价时保留空值。

汇率按每行船期相对业务月的期限选择：1–2个月用即期，3个月及以上用远期；4、5、7、8个月等使用相邻标准远期线性内插。显示的汇率是即期或远期全价，不是掉期点。

采集入口 `04_scripts/import_profit/capture_soybean_api.py` 在09:35运行，或同日15:00前补采，记录实际采集时间。`--backfill-pending` 后补最多8个保留日的美豆数据；`--backfill YYYY-MM-DD` 补指定日。原日国内价格和汇率保持原快照。

`--manual-cbot-date YYYY-MM-DD --evidence-file <原始截图路径>` 从标准输入读取 JSON：以完整合约年月（如2611）为键，值为美分/蒲式耳报价，如 `{"2611":1299.50,"2701":1316.25}`。截图须为PNG或JPEG，按SHA-256归档，保留所有修订。只更新指定日的美豆，不修改国内行情、汇率或CNF；新截图替换该日原人工报价。未被船期映射使用的合约仍保存在凭证记录中。

可选 `--quoted-at` 记录带时区的实际报价时间；没有时间时保存为空，页面提示时间未知，不称为09:00报价。再次采集或Databento回填不会覆盖用户报价。补入时必须已有该日行情快照。

本地预览须显式设置 `SOYBEAN_MARGIN_LOCAL_PREVIEW=1`，快照写入系统LocalAppData的独立 `market-data-runtime/soybean-api` 目录，凭据由仓库外 `--secret-file` 或环境变量提供。页面用 `SOYBEAN_MARGIN_API_ROOT` 指向该目录；正式运行读取既有快照挂载的 `soybean-api` 子目录，写入需要有效服务上下文。这里提供采集入口，不自动启动生产定时任务。

2026-10-08前行情保留历史和 Public Current；原数据更新完成发布及同步后可重新读取。所有日期以页面的业务日期、实际采集时间和缺失原因判断新鲜度；页面打开和 CNF 保存不触发供应商采集。

部署、数据更新、清理分别按[标准开发与生产发布规范](../03_标准开发与生产发布规范.md)执行，本地已采集或网页可访问不等于生产定时任务已经启用。
