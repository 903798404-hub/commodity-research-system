# 美豆种植生长周度更新契约

> 文档状态：当前项目专项契约。本文保护美豆周度数据、密钥、批次一致性和运行身份。

## 1. 执行入口

本地入口：

```bash
python 04_scripts/soybean_crop_progress/update_soybeans_crop_weekly.py --dry-run
python 04_scripts/soybean_crop_progress/update_soybeans_crop_weekly.py
python 04_scripts/soybean_crop_progress/update_soybeans_crop_weekly.py \
  --git-head <40位完整Git提交>
```

行为：

- 按 `America/New_York` 日期选择当前年度；
- 正常检查季为每年 4 月 1 日至 11 月 30 日；
- 季外返回 `out_of_season`；
- `--force` 只用于明确批准的季外运行；
- `--dry-run` 可以调用真实 API 并生成 Raw、Manifest、候选和临时审计，但不得替换稳定数据或固定状态。

## 2. 凭据和 Git 身份

API Key 只从 `NASS_API_KEY` 读取。

Git 提交解析优先级：

1. `--git-head`
2. `MARKET_DATA_GIT_HEAD`
3. 当前工作目录的 `git rev-parse HEAD`

命令行或环境变量存在时必须是 40 位十六进制 SHA。无法确定有效 Git SHA 时，应在请求 USDA API 前失败，不得使用 `UNKNOWN`、空值或伪造值。

同一提交号必须写入 Raw Manifest、JSON/Markdown 审计、状态文件和日志。

页面缓存键必须包含实际读取文件的 mtime，使稳定文件更新后页面自动失效，不要求重启容器。

## 4. 合并和原子切换

每次只请求当前年度的：

```text
PROGRESS/CONDITION × NATIONAL/STATE
```

更新逻辑：

- 保留当前年度以前的所有稳定行；
- 删除旧的当前年度行；
- 使用本次完整当前年度标准化结果替换；
- 捕捉新增周次、当年历史修正、新指标和新州；
- 不做插值、补零、前向填充或后向填充。

两个候选 Parquet 必须全部写入并通过质量校验后，才进入正式切换。

切换要求：

1. 创建同批恢复来源；
2. 写正式目录临时文件；
3. 重新检查 SHA-256 和可读性；
4. 按契约切换两个文件；
5. 切换后再次验证；
6. 任一失败恢复同批旧文件；
7. 首次初始化失败时移除本批已安装文件。

不得形成 Progress 和 Condition 来自不同批次的状态。

## 5. 服务器包装脚本

正式包装脚本：

```text
/home/ubuntu/market-data/09_deploy/soybean_crop_progress/run_soybean_crop_weekly_update.sh
```

固定职责：

1. 检查正式仓库和宿主机命令；
2. 使用 `/run/lock/soybean_crop_progress_update.lock` 非阻塞锁；
3. 非执行式读取仓库外 `/home/ubuntu/.config/market-data/nass.env`；
4. 要求恰好一个非空 `NASS_API_KEY`；
5. 读取并验证正式完整 Git SHA；
6. 确认 `spread-dashboard` 正在运行；
7. 临时导出 Key 和 Git SHA；
8. 执行容器内入口并原样返回退出码；
9. 退出时 unset 敏感变量。

容器调用只传变量名：

```bash
docker exec \
  --env NASS_API_KEY \
  --env MARKET_DATA_GIT_HEAD \
  spread-dashboard \
  python /app/04_scripts/soybean_crop_progress/update_soybeans_crop_weekly.py
```

不得使用 `--env NASS_API_KEY=<值>`，不得把 Key 值写入 cron、日志或容器永久配置。

## 6. 定时任务边界

拟定检查时间为北京时间每周二、周三、周四 06:30。正式任务是否已安装必须在服务器重新核验，不能仅凭文档推断。

cron 只调用包装脚本，不拼接长 `docker exec`：

```cron
30 6 * * 2-4 /usr/bin/bash /home/ubuntu/market-data/09_deploy/soybean_crop_progress/run_soybean_crop_weekly_update.sh >> /var/log/market-data-soybean-weekly-cron.log 2>&1
```

安装或修改 cron/systemd 属于单独生产任务，必须获得明确授权。

## 8. 停止条件

- Git SHA 无法确定；
- Key 缺失、为空、重复或权限不符；
- 锁冲突；
- API、标准化或候选质量校验失败；
- 两个候选不是同一批；
- 稳定文件切换后身份不一致；
- 正式容器不存在；
- 试图把 Key 写入命令、cron、日志或 Git；
- 试图在本地任务中读取服务器密钥或修改生产定时器。
