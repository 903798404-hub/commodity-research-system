# 美豆种植生长周度更新契约

> 文档状态：当前项目专项契约。本文保护美豆周度数据、密钥、批次一致性和运行身份。

## 1. 执行入口

本地入口：

```bash
python 04_scripts/soybean_crop_progress/update_soybeans_crop_weekly.py --dry-run
python 04_scripts/soybean_crop_progress/update_soybeans_crop_weekly.py
python 04_scripts/soybean_crop_progress/update_soybeans_crop_weekly.py \
  --git-head <40位完整Git提交>
```

行为：

- 按 `America/New_York` 日期选择当前年度；
- 正常检查季为每年 4 月 1 日至 11 月 30 日；
- 季外返回 `out_of_season`；
- `--force` 只用于明确批准的季外运行；
- `--dry-run` 可以调用真实 API 并生成 Raw、Manifest、候选和临时审计，但不得替换稳定数据或固定状态。

## 2. 凭据和 Git 身份

API Key 只从 `NASS_API_KEY` 读取。

Git 提交解析优先级：

1. `--git-head`
2. `MARKET_DATA_GIT_HEAD`
3. 当前工作目录的 `git rev-parse HEAD`

命令行或环境变量存在时必须是 40 位十六进制 SHA。无法确定有效 Git SHA 时，应在请求 USDA API 前失败，不得使用 `UNKNOWN`、空值或伪造值。

同一提交号必须写入 Raw Manifest、JSON/Markdown 审计、状态文件和日志。

## 3. 数据文件

| 类型 | 路径 |
|---|---|
| Stable Progress | `01_data/processed/soybean_crop_progress/soybeans_crop_progress_weekly.parquet` |
| Stable Condition | `01_data/processed/soybean_crop_progress/soybeans_crop_condition_weekly.parquet` |
| 首次上线基线 | 同目录两个 `*_2021_2026.parquet` |
| Raw/Manifest | `01_data/raw/soybean_crop_progress/` |
| Candidates | `01_data/candidates/soybean_crop_progress/<run_id>/` |
| Backups | `01_data/backups/soybean_crop_progress/<UTC时间>/` |
| 状态 | `01_data/update_status/soybean_crop_progress.json` |
| 更新审计 | `06_outputs/audits/soybean_crop_progress/updates/` |
| Dry-run 审计 | `06_outputs/audits/soybean_crop_progress/dry_runs/` |
| 日志 | `10_logs/soybean_crop_progress/` |

页面缓存键必须包含实际读取文件的 mtime，使稳定文件更新后页面自动失效，不要求重启容器。

## 4. 合并和原子切换

每次只请求当前年度的：

```text
PROGRESS/CONDITION × NATIONAL/STATE
```

更新逻辑：

- 保留当前年度以前的所有稳定行；
- 删除旧的当前年度行；
- 使用本次完整当前年度标准化结果替换；
- 捕捉新增周次、当年历史修正、新指标和新州；
- 不做插值、补零、前向填充或后向填充。

默认本地路径仍写两个候选 Parquet。服务器受控增量运输路径先在内存还原两表并通过完整质量校验，再独立生成两份兼容 Parquet 后进入正式切换；稀疏 JSON 负载不能直接作为正式 Parquet 安装。

切换要求：

1. 创建同批恢复来源；
2. 写正式目录临时文件；
3. 重新检查 SHA-256 和可读性；
4. 按契约切换两个文件；
5. 切换后再次验证；
6. 任一失败恢复同批旧文件；
7. 首次初始化失败时移除本批已安装文件。

不得形成 Progress 和 Condition 来自不同批次的状态。

## 5. 服务器包装脚本

正式包装脚本：

```text
/home/ubuntu/market-data/09_deploy/soybean_crop_progress/run_soybean_crop_weekly_update.sh
```

固定职责：

1. 检查正式仓库和宿主机命令；
2. 使用 `/run/lock/soybean_crop_progress_update.lock` 非阻塞锁；
3. 非执行式读取仓库外 `/home/ubuntu/.config/market-data/nass.env`；
4. 要求恰好一个非空 `NASS_API_KEY`；
5. 读取并验证正式完整 Git SHA；
6. 确认 `spread-dashboard` 正在运行，并读取其完整 Image ID、Git SHA 与 OCI revision；
7. 临时导出 Key 和 Git SHA；
8. 使用同一正式 Image ID 启动一次性更新容器，将宿主机 `01_data`、`06_outputs`
   和 `10_logs` 以读写方式挂载到更新容器；
9. 执行容器内入口并原样返回退出码；
10. 退出时 unset 敏感变量。

容器调用只传变量名：

```bash
docker run --rm \
  --env NASS_API_KEY \
  --env MARKET_DATA_GIT_HEAD \
  --mount type=bind,src=/home/ubuntu/market-data/01_data,dst=/app/01_data \
  --mount type=bind,src=/home/ubuntu/market-data/06_outputs,dst=/app/06_outputs \
  --mount type=bind,src=/home/ubuntu/market-data/10_logs,dst=/app/10_logs \
  --entrypoint python \
  <正式spread-dashboard完整Image-ID> \
  /app/04_scripts/soybean_crop_progress/update_soybeans_crop_weekly.py
```

不得使用 `--env NASS_API_KEY=<值>`，不得把 Key 值写入 cron、日志或容器永久配置。
一次性更新容器的业务数据挂载保持读写；正式 Web 容器的 `/app/01_data` 保持只读。

## 6. 定时任务边界

服务器独立采集器的稀疏运输模式使用互不包含的只读基线与候选输出目录，强制
`dry_run=True`，仍完整校验 Progress/Condition 两表。运输只包含授权当年的变化行、
移除键及统一来源元数据，并绑定每个实际基线文件 SHA；历史年业务字段不得改变。
采集前不复制四个 stable/legacy Parquet，无变化不生成整表候选或发布备份。
原始来源快照、Manifest、质量报告及失败证据仍保存，不补零或伪造新周。

独立断网精确镜像负责还原、原完整性校验和历史比较。只有业务变化才在隔离可写
scratch 生成两份旧 schema 兼容 Parquet；受保护宿主比较独立验证与生成报告、
SHA/Schema/行数及 UID，封为只读后走原有双表原子切换、备份和回滚，避免跨批次。
宿主本身不加载 pandas/Arrow，运输 JSON 不得直接写入正式 Parquet。默认本地入口
继续原有完整候选路径。镜像打包、实际 Linux 权限、实际发布/回滚及旧页面读者
未完成验收时，不得把本地稀疏 fixture 通过称为正式上线。

拟定检查时间为北京时间每周二、周三、周四 06:30。正式任务是否已安装必须在服务器重新核验，不能仅凭文档推断。

cron 只调用包装脚本，不拼接长 `docker exec`：

```cron
30 6 * * 2-4 /usr/bin/bash /home/ubuntu/market-data/09_deploy/soybean_crop_progress/run_soybean_crop_weekly_update.sh >> /var/log/market-data-soybean-weekly-cron.log 2>&1
```

安装或修改 cron/systemd 属于单独生产任务，必须获得明确授权。

## 8. 停止条件

- Git SHA 无法确定；
- Key 缺失、为空、重复或权限不符；
- 锁冲突；
- API、标准化或候选质量校验失败；
- 两个候选不是同一批；
- 稳定文件切换后身份不一致；
- 正式容器不存在；
- 试图把 Key 写入命令、cron、日志或 Git；
- 试图在本地任务中读取服务器密钥或修改生产定时器。
