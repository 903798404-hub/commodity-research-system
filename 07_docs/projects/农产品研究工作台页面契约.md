# 农产品研究工作台页面契约

> 文档状态：当前项目专项契约。本文只规定呈现方式，不改变数据、更新、路由、容器或部署规则。

## 1. 适用范围

- 应用：`spread-dashboard`
- 页面：首页、侧边栏和共享展示组件
- 固定名称：农产品研究工作台

首页只承担：

- 模块导航；
- 数据更新时间摘要；
- 模块状态；
- 异常和人工维护提醒；
- 内部页面和外部应用入口。

首页不得计算业务结果、执行更新任务、加载大量历史明细或将不完整数据描述为正常。

## 2. 信息架构

侧边栏按研究任务分组：

| 分类 | 页面或入口 |
|---|---|
| 工作台 | 首页 |
| 市场行情 | 价差动态；基差与一口价 |
| 周度跟踪 | 美豆种植生长；未来美豆出口相关能力 |
| 国际供需 | USDA；Oil World |
| 研究工具 | 外资与重点席位；运行监控 |

新增数据优先进入现有模块的内部页面、Tab 或筛选。只有形成独立、长期研究体系时才评估新增首页模块。

## 3. 首页结构

从上到下：

1. 顶部工作台区域；
2. 六个核心研究入口；
3. 需要关注；
4. 数据状态概览；
5. 简洁页脚。

“最近访问”和“自定义首页”不属于当前契约，不保留占位卡片或误导性入口。

## 4. 六个核心入口

| 显示 | 类型 | 状态语义 |
|---|---|---|
| 市场价格 | 内部页面 | 自动更新；显示业务更新时间 |
| 国内现货 | 内部页面 | 人工维护；不得称为实时 |
| 美豆周度跟踪 | 内部页面 | 周度节奏；不能按日度标准误报异常 |
| USDA 供需平衡 | 外部应用 | 只从 `USDA_DASHBOARD_URL` 解析 |
| Oil World 供需平衡 | 外部应用 | 只从 `OIL_WORLD_DASHBOARD_URL` 解析 |
| 运行监控 | 内部页面 | 详情和日志不在首页展开 |

外资与重点席位位于研究工具或数据状态区域，不占用核心卡片。部分失败时必须如实显示。

## 5. 状态语义

| 状态 | 使用条件 | 展示要求 |
|---|---|---|
| 正常 | 最近一次更新成功且无已知完整性问题 | 克制的成功标签和更新时间 |
| 人工维护 | 无定时自动更新承诺 | 标注人工维护，不使用“实时” |
| 每周更新 | 按周发布或检查 | 显示最新周次，不按日度告警 |
| 部分可用 | 部分源失败或结果待核验 | 明确警告并进入“需要关注” |
| 暂不可用 | 入口、数据或加载失败 | 清晰降级，其他模块继续可用 |
| 外部应用 | 独立应用提供服务 | 由有效环境配置和服务状态决定 |

当前状态必须从稳定文件和状态 JSON 读取，不得在契约中硬编码业务日期、行数或“当前正常”。

## 6. 视觉基线

方向：浅冷灰背景、白色表面、深蓝灰主文字、低饱和状态色，信息层级优先于装饰。

| 变量 | 基线值 |
|---|---|
| `page_background` | `#F4F6F8` |
| `surface_background` | `#FFFFFF` |
| `surface_border` | `#E3E8EF` |
| `text_primary` | `#172033` |
| `text_secondary` | `#667085` |
| `accent_primary` | `#2457A7` |
| `status_success` | `#2E7D5B` |
| `status_warning` | `#B7791F` |
| `status_error` | `#C2413B` |
| `status_info` | `#3B6EA8` |
| `card_radius` | `12px` |
| `card_shadow` | `0 2px 8px rgba(23, 32, 51, 0.06)` |
| `content_max_width` | `1440px` |
| `section_gap` | `24px` |
| `card_gap` | `16px` |

数值可在视觉验收时小幅调整，但不得让每个页面自行定义主题。

禁止大面积渐变、玻璃拟态、霓虹色、闪烁、复杂背景和大量装饰动画。不得隐藏失败或为对齐截断关键业务信息。

## 7. 共享组件边界

共享组件可以负责：

- 页面头部；
- 分区标题；
- 模块卡片；
- 状态标签；
- 更新时间；
- 需要关注；
- 外部入口；
- 空状态和错误降级。

不得负责：

- 写入数据；
- 执行更新任务；
- 业务计算；
- 改变路由；
- 保存个人配置；
- 替代现有模块的数据读取。

## 8. 外部应用降级

环境变量缺失时：

- 首页继续启动；
- 对应卡片显示暂不可用；
- 按钮禁用或不显示；
- 其他模块不受影响；
- 不使用 catalog 中的本地示例地址作为生产回退。

## 9. 响应式

- 宽屏：核心卡片多列排列。
- 普通笔记本：自动减少列数，标题、状态和按钮不溢出。
- 窄屏：自然换行，不依赖固定宽度或横向滚动读取主要内容。

## 10. 验收

进入候选前至少证明：

1. `spread-dashboard` 正常启动；
2. 六个核心入口完整；
3. 现有内部页面和路由可访问；
4. 外部地址仅来自环境变量，缺失时正常降级；
5. 人工、周度、部分失败状态语义正确；
6. 笔记本和窄屏无关键内容溢出；
7. 定向测试、约定回归、语法检查和 `git diff --check` 通过。
