# 农产品研究工作台页面契约

> 文档状态：当前项目专项契约。本文只规定呈现方式，不改变数据、更新、路由、容器或部署规则。

## 1. 适用范围

- 应用：`spread-dashboard`
- 页面：首页、侧边栏、共享展示组件及后续开发的研究图表
- 固定名称：农产品研究工作台

首页是整个研究系统的展开式研究导航，只承担：

- 展开侧边栏的研究信息架构；
- 提供内部页面和外部应用入口；
- 使用简短静态文字说明模块用途、功能集合或地域覆盖。

首页不得计算业务结果、执行更新任务、加载历史明细或展示运行健康状态。数据更新时间、
任务状态、Cron 状态、数据健康、正常/异常和异常提醒统一由“运行监控”承担。

## 2. 单一导航事实源

左侧侧边栏是所有页面中的紧凑型快速导航；首页是同一导航体系的展开页。两者必须读取
同一套导航事实源，并保持分组、名称、目标页面、路由和外部地址变量一致。

首页不得维护独立的“核心研究入口”配置，也不得创建第三套平行导航配置。首页不生成
“工作台首页”自身的卡片，其余研究入口原则上一一对应。

当前信息架构：

| 分类 | 页面或入口 |
|---|---|
| 工作台 | 工作台首页 |
| 市场行情 | 价差动态；国内现货（基差与一口价） |
| 周度跟踪 | 美豆周度跟踪 |
| 天气研究 | 大豆天气；菜籽天气；棕榈油天气；印度作物天气 |
| 国际供需 | USDA供需平衡；Oil World供需平衡 |
| 研究工具 | 进口大豆榨利；外资与重点席位；运行监控 |

新增数据优先进入现有模块的内部页面、Tab 或筛选。只有形成独立、长期研究体系时才评估
新增导航入口。

## 3. 首页结构

从上到下：

1. 工作台标题和低视觉权重的研究者信息；
2. “研究导航”及按侧边栏信息架构展开的分组卡片；
3. 简洁页脚。

首页不再保留“核心研究入口”“需要关注”“数据状态概览”“最近访问”或“自定义首页”。

顶部保留：

- 主标题：农产品研究工作台；
- 主标题下方左对齐展示：`徐晓冉 · 13305642778 · xx20236@outlook.com`。

首页不展示研究范围副标题，也不展示 `Agricultural Commodities Research`。

个人信息必须弱于主标题，不使用头像、不形成大型个人名片，也不在侧边栏 Logo 区重复姓名。

## 4. 卡片内容

每张卡片只展示：

- 与侧边栏一致的模块名称；
- 一句简短、稳定的研究用途说明；
- 必要的静态“包含”或“覆盖”说明；
- 进入模块的入口。

功能集合型模块使用“包含”，地域集合型模块使用“覆盖”。这些是低视觉权重的研究范围
说明，不得设计成正常/异常状态的彩色 Badge。

首页卡片不得展示：最新业务日、更新时间、自动或每周更新、数据可用、正常/异常、
Cron、刷新状态、外部 API 状态或其他动态运行信息。

静态范围基线：

| 入口 | 静态范围说明 |
|---|---|
| 美豆周度跟踪 | 包含：种植进度 · 生长状况 · 出口销售 · 出口装船 |
| 大豆天气 | 覆盖：美国 · 巴西 · 阿根廷 |
| 菜籽天气 | 覆盖：加拿大 · 澳大利亚 · 欧盟 · 俄罗斯 · 乌克兰 |
| 棕榈油天气 | 覆盖：印度尼西亚 · 马来西亚 |
| 印度作物天气 | 包含：棉花 · 甘蔗 |

更细的州、省、气象站、区域数量、模型、预测日期和数据状态只在对应模块内部呈现。

## 5. 运行状态边界

运行监控是合法研究工具入口，并应同时出现在侧边栏和首页展开导航中。运行监控现有功能、
数据读取和状态语义不因首页改版而改变。

侧边栏底部现有环境和“应用运行正常”文案不属于本次首页状态清理范围，继续保留。

## 6. 外部应用降级

外部应用地址只能来自既有环境变量。环境变量缺失时：

- 首页和侧边栏继续启动；
- 对应入口显示暂不可用并禁用；
- 其他模块不受影响；
- 不使用 catalog 中的本地示例地址作为生产回退。

## 7. 视觉基线

方向：浅冷灰背景、白色表面、深蓝灰主文字、低饱和辅助色，信息层级优先于装饰。

| 变量 | 基线值 |
|---|---|
| `page_background` | `#F4F6F8` |
| `surface_background` | `#FFFFFF` |
| `surface_border` | `#E3E8EF` |
| `text_primary` | `#172033` |
| `text_secondary` | `#667085` |
| `accent_primary` | `#2457A7` |
| `card_radius` | `12px` |
| `card_shadow` | `0 2px 8px rgba(23, 32, 51, 0.06)` |
| `content_max_width` | `1440px` |
| `section_gap` | `24px` |
| `card_gap` | `16px` |

卡片数量增加后，优先通过清晰分组、响应式列数和适度纵向滚动保持可读性，不得为了减少
滚动过度压缩卡片。禁止大面积渐变、玻璃拟态、霓虹色、闪烁、复杂背景和大量动画。

## 8. 共享组件边界

共享展示组件可以负责页面头部、分区标题、导航卡片、外部入口、空状态、错误降级和图表配色。

不得负责写入数据、执行更新任务、业务计算、改变正式路由、保存个人配置或替代模块数据读取。

## 9. 响应式

- 宽屏：分组内卡片多列排列，优先适配 1920×1080。
- 普通笔记本：自动减少列数，标题、说明和按钮不溢出。
- 窄屏：自然换行，不依赖固定宽度或横向滚动读取主要内容。

## 10. 验收

本地开发阶段至少证明：

1. 正式 `streamlit_app.py` 主入口正常启动；
2. 侧边栏导航保持完整；
3. 首页除“工作台首页”外与侧边栏入口、分组、名称和目标一致；
4. 首页不存在旧六卡契约、需要关注、数据状态概览或动态状态；
5. 研究者信息及静态“包含/覆盖”说明完整；
6. 内部路由可访问，外部地址缺失时正常降级；
7. 笔记本和窄屏无关键内容溢出；
8. 定向测试、约定影响测试、语法检查和 `git diff --check` 通过；
9. 浏览器验收来自真实 Streamlit 主入口，独立 renderer 或 AppTest 不能替代真实主入口验收。

## 11. 图表标准

后续新增图表及涉及样式的开发沿用已确认的国际价差与加拿大进度图配色。共享颜色、线宽和差异单元格样式的唯一代码定义为 [chart_style.py](../../03_src/agri_research_agent/shared/chart_style.py)；页面引用该模块，避免各自复制或重新选择颜色。加拿大进度图是季节进度图的参考实现；本标准只规定呈现，不计算或修改业务数据。

| 角色 | 颜色与样式 |
|---|---|
| 当年／所选对比年份 | `#C1493F` 红色实线，线宽3.4，完全不透明，优先显示于历史曲线上方 |
| 历史年份 | 使用固定年份色，线宽2；季节进度图透明度0.55，使当年更突出 |
| 同期均值 | `#667085` 灰色虚线，线宽2；在图例中写明均值口径 |
| 网格 | `#E1E5E9`，白色绘图区 |
| 高于均值 | 文字 `#A6342B`，底色 `#FCE8E6`，加粗，保留正号 |
| 低于均值 | 文字 `#174C91`，底色 `#E5EFFB`，加粗，保留负号 |
| 零差异／缺失 | 不加方向底色；缺失显示“—”，不补成零 |

历史年份以2021年为配色起点，按下表顺序循环；使用 `historical_year_color(year)` 取色，不按已选择曲线的排列位置分配颜色。同一个历史年份在不同省份、指标和选项组合中保持同色；所选对比年份始终优先使用红色。

|---|---|
| 2021 | `#0068C9` |
| 2022 | `#83C9FF` |
| 2023 | `#FF2B2B` |
| 2024 | `#FFABAB` |
| 2025 | `#29B09D` |
| 2026 | `#7DEFA1` |
| 2027 | `#FF8700` |
| 2028 | `#FFD16A` |
| 2029 | `#6D3FC0` |
| 2030 | `#D5DAE5` |

季节进度图默认显示2022年起已有的此前历史年份、所选年份及同期均值，更早年份可选。图例优先放在顶部，窄屏可换行；当年同时使用文字标识和清晰线条，不只靠颜色区分。缺失和未来数据不插值、不延长；均值年份、匹配窗口及有效样本数由各业务契约定义，不能以标准化样式替代取数口径。表格颜色只表示高低，不直接代表好坏、单产或价格方向；单位和差异正负号必须明确。

既有国际价差图的历史曲线仍沿用原有色序，本次统一其当年红色的代码来源；其余历史图表在后续开发涉及样式时逐步采用固定年份取色，不要求为配色重做全部页面。
