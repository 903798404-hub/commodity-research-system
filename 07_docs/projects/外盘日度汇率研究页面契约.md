# 外盘日度汇率研究页面契约

## 范围与阶段

应用为现有农产品研究工作台，页面名为“外盘汇率”，放在“市场行情”。首页和侧边栏沿用同一导航事实源。首期完成只读页面、官方数据解析和本地快照预览，不安装定时任务，不发布服务器，不改写现有榨利、持仓或加拿大数据。

巴西来源：[官方序列说明](https://dadosabertos.bcb.gov.br/dataset/1-taxa-de-cambio---livre---dolar-americano-venda---diario)。其他币种来源：[ECB参考汇率说明与下载](https://www.ecb.europa.eu/stats/policy_and_exchange_rates/euro_reference_exchange_rates/html/index.en.html)。ECB API见[官方示例](https://data.ecb.europa.eu/help/api/data-examples)。汇率驱动说明参考[澳洲央行](https://www.rba.gov.au/education/resources/explainers/drivers-of-the-aud-exchange-rate.html)。

统一存储1美元兑换的本币数额。ECB使用同一业务日的“1欧元兑本币参考价÷1欧元兑美元参考价”换算，不能跨日补分母，不能以ECB的BRL替换BCB序列，不能把CNY当CNH。各来源参考时点与日历不同，不合并成同一盘中时点，不称为市场最后成交价。

## 数据与计算

快照版本为`foreign-fx-daily/1`。顶层保留带时区的`generated_at`、`sources`及`observations`。来源保留provider、URL、采集时间、原始响应SHA-256与换算方法。观察字段为`currency`、ISO业务日`date`、数值`local_per_usd`及`provider`。

唯一键为币种加业务日期。重复、未知币种、来源不匹配、非正/非有限数值、未来日期及身份缺失直接拒绝。每个币种独立按日期排序；缺失保留缺失，不填零或沿用报价。日度涨跌使用相邻有报价日，5日和20日使用各自5/20个报价间隔，不称为自然日变化。

本币相对美元收益为`previous/current-1`。多币种强弱比较使用所选区间内所有币种共同有报价的最早日期作为100起点，指数为`base/current*100`。没有共同报价日时显示不可比较，禁止默用各自不同起点。汇率变化只提供研究背景，不做政策或商品价格的因果归因。

## 读取与预览边界

页面默认只读`01_data/processed/foreign_fx/daily.json`，亦可由显式`FOREIGN_FX_SNAPSHOT_FILE`指定只读快照。没有文件时呈现币种范围，无伪造行情。数据损坏时报告不可用，不影响其他页面。页面不请求外部API、不执行采集或更新。

开发预览入口为`04_scripts/foreign_fx/build_preview.py`，输出固定在该检出自己的`06_outputs/foreign_fx_preview/daily.json`。不提供production/root/output改写参数，不写`01_data`。抓取、解析和覆盖校验全部通过后才原子替换预览文件，失败保留此前有效预览；数据不进入普通Git提交。

首期不注册自动更新链。正式运行的raw/candidate/stable/backup/status、独立锁、修订策略、身份和上线安排须在启用正式采集前补齐本契约；代码合入不代表正式数据已经导入。

## 页面与验收

页面包含各币种最新业务日期、汇率与1/5/20报价日的本币涨跌，默认单币种季节性，共同起点的本币强弱比较，来源/计算口径和CSV下载。季节性支持年份选择、汇率水平与年初100指数。今年按上海时区的自然年标识，使用共享粗红线；历史年份使用共享年度颜色和透明度。每年实际月日映射至闰年2000，2月29日独立保留，3月以后不因闰年错位。年初指数以各年首个有报价日为基准，`当日汇率/年初汇率*100`；方向与本币强弱指数相反，页面明确说明。历史月度均值仅使用所选的当年之前的历史年份，先对各年每月的实际报价求均值，再对年份等权平均；各月至少2个年份有报价才显示，参考点位于月中，不含今年，不补缺失，不把图形对齐作为稳定季节规律的证明。引用现有共享图表颜色。参考币种计价差异与出口政策在“数据与研究含义”中说明。

必须核验逆向收益、同日交叉换算、不同日历与共同起点、异常/空数据降级、原导航保持、数据页只读、中文UTF-8、打包闭包及真实Streamlit主入口。首期本地验证与正式服务器验收分别报告。
