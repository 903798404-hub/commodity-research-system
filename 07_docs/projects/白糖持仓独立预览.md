# 白糖资金情绪独立预览

页面的目标是直观看到持仓反映的多空倾向，以及这种倾向正在增强还是减弱。顶部同时展示糖11、伦敦白砂糖和郑糖的最新状态，下面提供净持仓趋势、净变化柱形图和五家固定席位明细。持仓变化不能解释成真实资金流入流出；套保与会员代客持仓也不能解释成单一机构的交易意图。

## 阅读页面

速览固定为外盘管理基金的纯期货口径、国内 SR 品种前20名排名。详情筛选不改变速览口径，避免切换分类后无意改变顶部比较对象。每个市场单独标注持仓截至日期和比较日期。

| 净持仓 | 净变化 | 页面提示 |
| --- | --- | --- |
| 正 | 正 | 偏多，增强 |
| 正 | 负 | 偏多，减弱 |
| 负 | 负 | 偏空，增强 |
| 负 | 正 | 偏空，减弱 |
| 零 | 有变化 | 多空平衡，向多或向空变化 |
| 已披露 | 不可比 | 仅显示多空倾向，变化不可比 |
| 未披露 | 任意 | 披露不足，情绪无法判断 |

该提示只描述观察到的持仓，未设置买卖信号或任意强弱阈值。外盘另展示净持仓/总持仓量，辅助观察相对倾向；各市场合约规格和交易者构成不同，不能用手数直接比较资金规模。

图表契约：横轴为持仓日期，纵轴为净持仓或净变化，单位为手，均有零线。净持仓使用折线，五家席位通过颜色和线型区分，缺失值断线。净变化使用柱形图，红色表示向多变化、绿色表示向空变化，并有文字图例；它不表示实际资金流向。外盘变动图展示最近26份报告。明细默认收起，保留多仓、空仓、比较日期和披露情况供核查。

## 来源与口径

| 市场 | 官方来源 | 本版粒度 |
| --- | --- | --- |
| 糖11 | CFTC Socrata，纯期货 72hh-3qpy、期货期权 kh3c-gbw2，市场代码 080732 | 周报；各到期月份汇总；五类交易者 |
| 伦敦白砂糖 | ICE 年度 COTHist{year}.csv，市场 W | 周报；各到期月份汇总；FutOnly/Combined 分开 |
| 国内 SR | 郑商所 FutureDataHolding.xlsx | 日报；品种总排名与各合约分别处理 |

外盘来源入口：[CFTC COT](https://www.cftc.gov/MarketReports/CommitmentsofTraders/index.htm)、[ICE COT](https://www.ice.com/report/122)。国内入口：[郑商所持仓排名](https://www.czce.com.cn/cn/jysj/ccpm/H077003004index_1.htm)。

CFTC API 为 https://publicreporting.cftc.gov/resource/{dataset}.json，使用实际 API 字段名称，不从 CSV 字段猜测。ICE 下载路径为 https://www.ice.com/publicdocs/futures/COTHist{year}.csv。国内路径为 https://www.czce.com.cn/cn/DFSStaticFiles/Future/{year}/{YYYYMMDD}/FutureDataHolding.xlsx；本版支持2025-11-02之后的 XLSX 格式，较早格式尚未接入。

外盘默认管理基金，产业商、掉期商、其他报告者、非报告者可切换。纯期货与期货期权报告独立存储，不能混合。合约月份基金持仓未由这些周报提供，页面不作月份分配。

国内净持仓指“公开排名多仓之和减空仓之和”，全市场多空总量本身相等，不能称为全市场净资金。前20名与前5名分别计算，多头和空头名单可能不同；净变化比较两份完整排名汇总，包含名单更替，不等于当日上榜会员增减量之和。

五家固定席位由用户指定为高盛/乾坤、摩根大通、永安、国泰君安、东证。名称映射保存于 02_configs/sugar_positions.json，保留原始会员名；不自动扩展到未核实的其他名称。代客、自营、未区分账户分别展示。每家必须多空两侧均披露才计算净持仓，五家全部完整才计算合计。未上榜不代表零仓位。

变化比较上一条已保存的同口径观察，显示具体比较日期；任一观察缺失或间隔超过10天时不计算变化。外盘报告超过14天会提示核对发布状态。周报持仓日期与公布日期不同，各市场不会强行对齐不同截至日期。

## 采集与数据保护

原始下载保留来源 URL、采集时间和 SHA256。先校验身份、日期、整数、重复业务键、排名和汇总，再写入版本快照；current.json 原子指向新版本，页面校验清单及快照哈希后读取。

纯期货外盘分类多空加跨期仓应与总持仓量一致；期货期权组合因四舍五入允许分类求和误差最多4手，CFTC 报告者汇总加非报告者误差最多1手，不修改原始数值。国内分别核对买卖侧原始合计及连续排名，忽略未披露的“-”会员占位行。

修订采用完整日期分区替换，避免保留已经退出排名的旧会员。部分来源失败时保留相关来源上一份已验证快照，并在页面提示；错误来源不发布为零。国内404记录为未发布，不自动认定为采集故障。并发写入由独占锁保护，不自动抢占遗留锁。

## 本地运行

在上述独立工作树运行。下面的 python 应指向已经通过仓库环境预检、依赖契约一致的解释器，本次只复用已有 .venv-py312，没有安装或升级依赖。

```powershell
python 04_scripts/sugar_positions/update_sugar_positions.py --markets all --start-year 2025 --czce-start 2026-09-01 --czce-end 2026-09-30
python -m streamlit run 05_apps/sugar_positions_preview.py --server.address 127.0.0.1 --server.port 8571 --server.headless true --browser.gatherUsageStats false
python -m pytest 08_tests/sugar_positions 08_tests/shared/test_module_test_map.py -q
```

默认采集外盘最近两年、国内最近42天。--markets 可选 foreign/domestic/all；已有国内日期默认跳过，--recheck-domestic 可重新校验修订。单次国内区间不超过120天，不接受未来日期。页面只读取本地快照，不自行触发采集。
