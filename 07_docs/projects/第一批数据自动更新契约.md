# 第一批数据自动更新

本契约覆盖加拿大 CGC 周度菜籽出口、坚果云国内基差及一口价、已实现官方来源的持仓。
不更新国际三油价差、天气、土壤、StatCan 月度贸易、作物省报、Oil World 或榨利人工报价。
数据任务与 main 接纳、应用代码部署分开；main 保持普通 fast-forward。

## 六项服务器直接更新

2026-10-11 本次获批切换范围调整为五项：AKShare 价差、内盘持仓、外盘持仓、
NASS 美豆生长、FAS 美豆销售。加拿大 CGC 官网完整下载未通过服务器验收，用户指定
继续本地更新，因此本次不安装/启用 CGC 服务器任务，不禁用原 Windows CGC 任务。
下表包含代码支持的六项能力，不代表六项均已切换；坚果云基差也保持原状。

可迁移的固定任务为 AKShare 价差、CGC 菜籽出口、内盘持仓、外盘持仓、NASS 美豆生长、
FAS 美豆销售。坚果云基差继续使用下述原 Windows 任务和精确工作簿，不改变来源或时间。
新增入口 `09_deploy/scheduled_server/run.py --config <protected-config>` 默认只生成隔离候选，
`--publish` 才走现有正式发布。服务器 root 只运行 stdlib，以固定 Python `-I -B` 从获批
独立浅克隆执行；每次核验 Commit/Tree、完整源码字节、固定 Image ID、数据盘 UUID、policy。
不依赖 Windows、登录状态、桌面浏览器、文件同步、SSH 回传或在主机临时安装依赖。

service 模板和 `render_units` 仅生成待验收 unit；实际安装与切换单独留证。Persistent=true
允许漏跑补检查；不把内盘第二窗口改为成功即跳过。两个持仓任务共用 commodity_positions
独占锁；本批网络采集串行控制资源，不停止既有应用或其他任务。
仅保持现有已实现的 SR/RS/OI/RM 自动持仓范围，不借迁移新增 DCE、FCPO 或 FGIS。

配置为封闭 `scheduled-server-config/1`，固定 job、policy/SHA、image、数据盘、producer、
allocation，以及相应 API 凭据路径或 AKShare 初始续接基线；不接受其他任务或任意源码。
NASS/FAS 凭据仅由受保护主机文件加载，经采集容器标准输入传入；不进入 Git、配置正文、
Docker 环境/命令、候选或日志。网络 worker 非 root、只读根文件系统、无 capabilities，
获批源码与基线 RO，仅本次隔离输出 RW；超时只清理本次唯一 worker。
拷贝前按本次基线大小估算采集、密封上传及新 release 共存空间，并额外预留 768 MiB；
余量不足在联网和数据写入前失败。AKShare 不把公共包再复制进计算项目。
只有正式回执、应用 POST_SWITCH 和价差续接均成功后，才逐文件核对本次临时公共包副本
与保留的不可变 release；保留哈希清单后释放已证明重复的 data 目录，以及 NO_CHANGE 的
本次唯一上传 data 副本。上传 manifest、正式 release、业务历史、三文件续接、其他任务
和失败候选均不清理。

CGC、持仓、NASS、FAS 每次从 allocation 锁下读真实正式基线，拷贝并核验 SHA/大小后采集；
随后 stage-upload、receive、固定镜像断网校验、CAS publish 和实际正式回执均不变。
NASS 保留季节规则、历史及 Progress/Condition 同批次；FAS 保留市场年和修订规则。
域外数据不进入采集可写挂载。隔离 CGC 候选沿用 isolated-dev marker，不具有正式写入权限；
正式数据始终由受保护发布器写入，不借 marker、伪造 .git 或环境变量绕过执行身份。

AKShare 初始基线仅复制获批价差三文件，核对其 Parquet 与实际 Public Current artifact 一致。
后续从服务器自己的密封续接副本读取；正式包从当前不可变 release 逐文件核验拷贝。
只更新 domestic-spread artifact，坚果云基差及所有其他 datasets 的字节身份保持一致。
与仍在 Windows 的基差不假装共用本地文件锁：服务器发布使用现有 `.current.lock` 和完整
旧 Current ID、manifest SHA、artifact SHA 的 CAS。基差在采集期间更新则本次候选失败，
重新从新 Current 构造；不覆盖基差、不放宽 CAS、不强推过时包。
沿用实际运行应用 PRE_SWITCH/POST_SWITCH 可读性门禁与失败回滚；不重启网站。

Public Current 的既有 transport owner UID/GID 固定在受保护配置中，快照核验实际 owner；
正式 publisher 继续用该非 root 账户运行，保持坚果云基差原有读写权限。仅新建 upload 的
ownership/ACL 可以封存，不改变既有 store、release、pointer 或运行账户权限。

每次持久 result/last-run 包含 server host、job、producer、采集结果、校验/回执和脱敏失败阶段。
NO_CHANGE 不代表新业务日；PARTIAL_FAILURE 不接受为全量验收。切换前每项须真实服务器
采集、候选校验、首次正式发布或 NO_CHANGE 回执、正式消费者验证通过；未通过项保留
原 Windows 任务。保存每个原 XML/配置和服务器恢复记录，只禁用对应已验收任务，不删除。
坚果云基差、汇率 timer、其他 cron/unit、应用容器、CNF/历史和人工文件保持原样。

## 固定执行入口

`04_scripts/automation/run_first_batch_scheduled.py --config <精确配置>` 默认生成隔离候选。
`--publish` 显式启用正式交付。必须使用获批绝对 Python `-I -B -X utf8`，从固定 Commit/Tree、
canonical origin、干净 detached 独立 control clone 运行，不能定时执行开发工作树。
配置使用封闭 `first-batch-scheduled-config/1`，含 job、runtime_root、delivery；未知键拒绝。
生产前核对源代码完整 Git archive、主机 policy/publisher SHA、校验镜像和实际 Current。
本地文件消费者不连接数据库；Tankan client 在真正连接时才加载 psycopg/行工厂。
驱动不可用时实际连接继续清除密码并 fail closed，不将本地文件校验变成数据库联网。

## 坚果云完整只读边界

`D:\坚果云\123` 全部禁止写入。只允许精确读取
`D:\坚果云\123\国内基差及一口价\基差数据.xlsx` 的 `油脂油料价格 basis_price` 原始表。
不扫描父目录或兄弟文件，不保存/刷新工作簿，不改名、不移动、不删除、不改变 ACL。

路径祖先的符号链接、junction 以及输出和输入重叠，在首次创建目录前拒绝。
上游文件没有更新时 NO_CHANGE；自动任务不会生成缺失的源报价。

## 正式续接和共享 Current

CGC/持仓每次正式执行通过受保护 `snapshot-baseline` 在 allocation 锁内只读取得固定域文件，
验证 policy、producer、image、SHA/大小、完整性和传输边界；不复用上次已过时的 baseline。
仅允许 foreign_fx、canola_exports、commodity_positions 固定域快照；不接受任意文件列表。
随后复用既有候选 → stage-upload → receive → 固定镜像断网来源重放 → publish 和回读回执。
数据与状态的无变化处理沿用原合同，NO_CHANGE 不假装新增业务日期。

基差读取当前服务器不可变公共包的精确 manifest 和列出的文件，逐文件核验 SHA，
复制前后 Current pointer 一致；包校验和实际消费者校验失败不发布。
与获批本地不可变基线完全匹配的文件只读复用，复制前后核验字节身份；源输入不写入。
新文件才从服务器下载，按文件大小设置 180–1200 秒上限，基线复制总预算 45 分钟。
本地基线损坏、源身份变化或总预算耗尽时停止，不能用未验证缓存或放宽 CAS 继续发布。
只替换基差 dataset；历史逐字段保留，价差 artifact 和其他公共 dataset 身份保持一致。
与既有价差任务使用同一 FULL DAILY 锁；候选公共包留在该任务现有认可的
`<full-daily-lock-parent>/runs/<唯一运行>/runtime/public-data-packages/<package_id>` 外部缓存，
使既有价差任务能够发现新 Current。缓存经完整 package 校验，不改动既有价差任务。
正式切换始终绑定旧 Current ID、manifest SHA、价差 artifact SHA，以及新包身份走 CAS；
Current 已移动则失败，下次重新读取，不强推旧候选。scope evidence SHA 复用 transport
`reconciliation-manifest-sha256` 字段记入回执，语义为基差追加及其他域不变的范围证据。

## 任务安装和验收

`register_first_batch_scheduled.ps1 -ConfigPath <配置>` 仅生成任务 XML；加 `-Install` 才注册。
安装前执行 pinned clone/config 预检，限定 China Standard Time；已有同名任务先导出 XML 备份。
任务以 LeastPrivilege、InteractiveToken、隐藏窗口、IgnoreNew、StartWhenAvailable 运行，最长 90 分钟。
它们依赖 Windows 在线且用户已登录；本合同不存储 Windows 密码、不扩大账户权限。
每个域外部独占锁；两个持仓任务共享同域锁。不抢占遗留锁，不启动并行同域 worker。

每次候选/正式运行记录 result.json 和独立 last-run：检查时间、producer、状态、实际 published、
来源尝试和正式回执；失败仍保留日志和旧正式数据。退出 0 可能为 NO_CHANGE，不等于有新数据。
自动上线验收须分别验证本机任务定义/下次时间、真实采集候选、主机固定镜像重放、
首次正式回执和正式消费者；代码/CI 成功不能替代任务安装与计划运行验收。
生产任务、policy 和数据交付以获批精确安装清单为准。既有任务、容器和运行目录保持原样。
新 policy 安装必须同时建立其独立 incoming、candidate、evidence、backup 目录，
只新增 root 所有的受保护目录，不修改旧目录权限；缺失时 publisher 会拒绝交付。
服务器 Python 调用同时使用 `-I -B`，publisher 自身也禁止生成字节码，避免导入业务模块
在固定源码检出内写入 `__pycache__` 而触发完整性拒绝；源码保护检查不能绕过。
无输入负载的子命令明确关闭标准输入，避免 Windows 任务环境下 OpenSSH 等待继承的
控制台输入；传送 JSON 或二进制负载的命令仍使用独立输入管道，逐字节传输不变。

回滚：禁用本批四个独立任务，保留外部状态/候选/证据；恢复此前同名任务 XML（如有）。
公共包和持仓/CGC 使用原有备份与回滚入口，不删除已验证历史，不改坚果云文件。
