## 3. 执行前核验

必须重新确认：

- `.ssh` 目录权限为预期最小权限；
- 私钥权限为 `0600`；
- 私钥所有者正确；
- 公钥内容和指纹匹配；
- 包装脚本所有者、权限和 SHA-256 匹配；
- 包装脚本启用严格主机校验；
- GitHub Deploy Key 仍为只读；
- `git ls-remote` 返回的远程 main SHA 符合本次批准目标；
- 服务器无法使用该身份 push。

任一项不一致时停止，不自动覆盖文件、不轮换密钥、不降低主机校验。

## 4. 轮换

密钥或包装脚本轮换必须是独立治理任务，同时更新：

- GitHub Deploy Key；
- 服务器公钥和私钥；
- 公钥指纹；
- 包装脚本；
- 包装脚本 SHA-256；
- 权限和所有者审计；
- 本登记的核验日期。

不得在本文、Git、日志、聊天、镜像或 Manifest 中记录私钥正文。
