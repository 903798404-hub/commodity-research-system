# 菜籽、大豆、棕榈油持仓预览

截至2026年10月8日，本功能为本地独立预览。资金情绪由净持仓正负及相邻同口径报告的变化描述；持仓变化不等于现金流入流出。

大商所批量下载接口在本机返回HTTP 412、text/html，而不是持仓ZIP。正文为空，包含三段脚本；旧排名页面为空白，正常官网首页连接关闭。这只能说明当前访问失败，不能确定是会话校验、防护规则、接口变化或网络访问条件，更不能证明必须购买权限或用户IP被封。未绕过挑战，未执行返回的脚本。已有本地foreign_seats历史的M/P/Y记录也都是source_error，不能用作真实持仓。

Euronext的2026年9月30日及10月7日报告明确标注FUTR/COMB，首版保存两份各口径报告；更早的报告未明确标注口径，先拒绝混入。合并期权的持仓为Delta等价手，保留两位小数；分类持仓之和不能当作交易所总持仓，open_interest保持空值。以各分类的Risk Reducing与Other明细核对Total。CFTC有管理基金分类，Euronext为投资基金分类，两者不能视为相同参与者集合。

## 计算与缺失

- 净持仓为多仓减空仓；变化为相邻已保存同市场、同口径、同交易者分类的净仓之差，展示比较日期，间隔超过10天不算变化。
- 国内前20名、前5名多空名单可以不同，变化包含名单更替；不称为全市场净持仓。
- 固定席位沿用白糖的高盛、摩根大通、永安、国泰君安、东证映射。郑商所默认代客；大商所原始文件未明确账户类型时保持未区分。未上榜的一侧保持空值，五家均完整才计算合计。
- 品种总排名与合约排名分开；不把多个合约排名汇总冒充品种总排名，不自动猜测或拼接主力合约。
- 页面没有真实数据时只显示缺口，不生成情绪、零仓位或示例走势图。FCPO总持仓不能代替基金净持仓。

## 隔离与运行

共用代码在03_src/agri_research_agent/oilseed_positions、05_apps/oilseed_positions_page.py；配置为02_configs/oilseed_positions.json。采集在04_scripts/oilseed_positions/update_positions.py，必须在独立linked worktree运行，只写该worktree下01_data/oilseed_positions_preview/板块。拒绝主检出和重定向目录。原始文件保存SHA-256，快照不可变，指针原子发布；来源失败保留上次已验证数据。网页只读、不请求外部来源。不会写大豆榨利或白糖预览数据。

三个入口及建议本地端口：rapeseed_positions_preview.py（8572）、soybean_positions_preview.py（8573）、palm_positions_preview.py（8574）。原有白糖端口8571保持运行。

采集命令示例（在对应独立worktree运行）：

```powershell
python 04_scripts/oilseed_positions/update_positions.py --domain rapeseed --domestic-start 2026-09-01 --end 2026-10-07 --euronext-start 2026-09-30
python 04_scripts/oilseed_positions/update_positions.py --domain soybean --markets foreign
python 04_scripts/oilseed_positions/update_positions.py --domain palm
python -m streamlit run 05_apps/rapeseed_positions_preview.py --server.address 127.0.0.1 --server.port 8572
```

采集退出码0表示本次请求已验证或官方文件404未发布；2表示存在失败或待确认来源，成功来源仍发布独立快照。大商所默认不继续自动尝试日期区间；只有明确传入--dce-seed-contract才单次请求一个日期。解析器已做单元验证，尚无下载成功的真实DCE ZIP来证明端到端可用。
