# 数据与输出目录说明

## 01_data

`01_data/` 保存正式运行数据，不纳入 Git，也不得在部署时覆盖或清空。

- `manual/`：人工维护或人工放入的源文件。
- `manual/basis/国内现货基差.xlsx`：固定的国内现货基差输入文件，程序读取但不主动改写。
- `manual/basis/backup/`：网页覆盖上传前生成的本地备份，不作为最新输入读取。
- `processed/`：清洗和标准化后的程序数据。
- `processed/basis_spread/`：国内基差、一口价、期货收盘价和现货价差标准表。
- `database/basis/basis_quotes.parquet`：基差页面正式数据库，由导入流程更新。
- `database/basis/basis_quotes_sample.parquet`：生产环境本地回退数据，仅在正式数据库缺失时读取，不纳入 Git。
- `backups/`：自动更新产生的正式数据备份。

测试使用的固定基差样例位于 `08_tests/fixtures/basis_quotes_sample.parquet`，与生产回退文件职责分离。

## 06_outputs

`06_outputs/` 保存程序生成结果，不纳入 Git。目录由程序按需创建：

- `charts/`：图片和图表。
- `excel/`：Excel 报表。
- `markdown/`：Markdown 日报和研究摘要。
- `push_logs/`：邮件、飞书等推送结果，不得记录密码或密钥。

长期规则、字段说明和操作手册应放入 `07_docs/`，不应放在生成输出目录中。
