# 农产品研究工作台页面契约

**适用应用：** `spread-dashboard`

**适用范围：** 首页、侧边栏和后续共享展示组件。本文件只规定呈现方式，不改变数据、计算、更新和路由。

## 1. 信息架构

### 1.1 侧边栏

侧边栏按研究任务分组，而非直接罗列所有页面。后续实现应保留现有页面能力，并按下列分类呈现。

| 分类 | 页面或入口 |
|---|---|
| 工作台 | 首页 |
| 市场行情 | 价差动态；基差与一口价 |
| 周度跟踪 | 美豆种植生长；未来的美豆出口销售、出口装船、出口检验 |
| 国际供需 | USDA 供需平衡；Oil World 供需平衡 |
| 研究工具 | 外资与重点席位；运行监控 |

新增数据优先扩展现有研究模块的内部页面、Tab 或筛选项。首页核心入口不应随数据文件数量增加；只有形成独立、长期使用的研究体系时，才评估新增首页模块。

### 1.2 首页职责

首页固定名称为“农产品研究工作台”，只承担：

- 模块导航；
- 数据更新时间摘要；
- 模块状态展示；
- 异常和人工维护提醒；
- 内部页面与外部应用入口。

首页不得加载大量历史图表、全部明细或错误堆栈，不得计算业务结果、执行更新任务、替代运行监控页面，或将不完整数据描述为完整正常。

### 1.3 首页结构

首页从上到下固定为以下区域：

1. 顶部工作台区域：页面名称、简短说明和总体更新时间语境。
2. 六个核心研究入口：稳定的研究模块导航卡片。
3. 需要关注：仅显示人工维护滞后、部分失败、入口缺失、加载失败或需要核验的事项；正常模块不重复显示。
4. 数据状态概览：展示模块状态、更新时间和更新类型的摘要；完整日志和任务细节仍在运行监控页面。
5. 简洁页脚：说明数据状态为摘要，并指向对应模块或运行监控。

“最近访问”和“自定义首页”不属于本阶段，也不得保留占位卡片、禁用按钮或误导性入口。

## 2. 六个核心入口

| 首页显示 | 对应现有能力 | 入口类型 | 首页状态语义 |
|---|---|---|---|
| 市场价格 | 价差动态页面 | 内部页面 | 自动更新；数据源为 AKShare，工作日北京时间 16:30 更新。 |
| 国内现货 | 基差与一口价页面 | 内部页面 | 人工维护；数据来自人工维护 Excel，不承诺实时或自动更新。 |
| 美豆周度跟踪 | 美豆种植生长页面，并为未来美豆出口相关页面预留内部扩展空间 | 内部页面 | 每周更新；USDA NASS 周度数据不因不是当天数据而标记异常。 |
| USDA 供需平衡 | USDA 独立应用 | 外部应用 | 外部应用；地址只从 `USDA_DASHBOARD_URL` 读取。 |
| Oil World 供需平衡 | Oil World 独立应用 | 外部应用 | 外部应用；地址只从 `OIL_WORLD_DASHBOARD_URL` 读取。 |
| 运行监控 | 运行监控页面 | 内部页面 | 监控入口；详情、日志和错误堆栈不在首页展开。 |

外资与重点席位不占用核心卡片位置。它位于“研究工具”导航或数据状态概览；当前已知状态为部分可用，不能展示为完整正常。

## 3. 模块状态语义

| 状态 | 使用条件 | 展示要求 |
|---|---|---|
| 正常 | 最近一次自动更新成功，且没有已知完整性问题。 | 使用克制的成功标签，可显示更新时间与“自动更新”。 |
| 人工维护 | 数据由人工更新，未承诺定时自动更新。 | 明确标注“人工维护”，可显示最近业务日期，不使用“实时”。 |
| 每周更新 | 数据按周发布或检查，日期不是当天属于正常业务节奏。 | 明确标注“每周更新”和最新周次，不以日度标准告警。 |
| 部分可用 | 部分数据源失败、部分数据缺失或结果仍待核验，但保留可用内容。 | 使用清晰警告标签，并在“需要关注”中说明事实。 |
| 暂不可用 | 入口、数据文件或加载过程缺失或失败。 | 显示明确降级文案；其他模块继续可用。 |
| 外部应用 | 由独立应用提供服务。 | 标明外部应用；是否可访问由有效配置和服务状态决定。 |

当前展示事实应以已有可信状态文件和稳定文件为准：

- 市场价格：`historical_spread_database.parquet`，AKShare，工作日 16:30（北京时间）更新；审计时最新业务日为 2026-07-17。
- 国内现货：`basis_quotes.parquet`，人工维护 Excel；审计时最新业务日为 2026-07-03，且当前无生产 cron 自动更新。
- 美豆种植生长：USDA NASS Quick Stats API，每周二至周四 06:30（北京时间）运行；审计时最新周截至 2026-07-12，最近一次为 `no_change`。
- 外资与重点席位：AKShare，DCE 官方文件兜底；审计时最新业务日为 2026-07-10，状态为 `partial_failure`，当前无生产 cron。

## 4. 视觉设计基线

视觉方向为浅冷灰背景、白色内容卡片、深蓝灰主文字和低饱和辅助色的专业投研终端风格。信息层级优先于装饰性，边框、圆角与阴影保持克制。

| 语义变量 | 建议值 | 用途 |
|---|---|---|
| `page_background` | `#F4F6F8` | 页面背景。 |
| `surface_background` | `#FFFFFF` | 内容区与卡片表面。 |
| `surface_border` | `#E3E8EF` | 卡片、分区和弱分隔线。 |
| `text_primary` | `#172033` | 标题、正文和重要数值。 |
| `text_secondary` | `#667085` | 辅助说明、时间和次级标签。 |
| `accent_primary` | `#2457A7` | 主操作、当前导航和受控强调。 |
| `status_success` | `#2E7D5B` | 正常状态。 |
| `status_warning` | `#B7791F` | 人工维护、部分可用或待核验。 |
| `status_error` | `#C2413B` | 暂不可用或明确失败。 |
| `status_info` | `#3B6EA8` | 外部应用、周度更新等中性信息。 |
| `card_radius` | `12px` | 所有主卡片的统一圆角。 |
| `card_shadow` | `0 2px 8px rgba(23, 32, 51, 0.06)` | 轻量层级，不代替边框。 |
| `content_max_width` | `1440px` | 宽屏下内容最大宽度。 |
| `section_gap` | `24px` | 首页主要区块之间的间距。 |
| `card_gap` | `16px` | 同一区块内卡片间距。 |
| `title_size` | `28px` | 首页主标题基线。 |
| `section_title_size` | `18px` | 分区标题基线。 |
| `body_size` | `14px` | 常规正文基线。 |
| `caption_size` | `12px` | 时间、来源和辅助说明基线。 |

后续本地视觉验收可小幅调整这些数值，但不得让每个页面自行定义一套主题。

禁止大面积渐变、玻璃拟态、霓虹色、复杂背景图、夸张动画、闪烁、大量装饰性图标和大面积高饱和红绿。品种识别色只用于图表或局部标签，不作为页面主色。不得为了对齐而截断关键业务信息，也不得将失败或部分失败隐藏为弱提示。

## 5. 共享展示组件契约

后续可在 `05_apps/` 中创建共享展示模块，建议包括：

- 页面头部；
- 分区标题；
- 模块入口卡片；
- 状态标签；
- 更新时间展示；
- 需要关注提示；
- 外部应用入口；
- 空状态；
- 错误降级提示。

共享组件只负责展示和可访问性，不得写入 Parquet、执行更新任务、处理业务计算、改变路由、替代现有业务模块的数据读取逻辑，或保存用户个人配置。

## 6. 外部应用降级规则

USDA 和 Oil World 地址必须分别从 `USDA_DASHBOARD_URL` 与 `OIL_WORLD_DASHBOARD_URL` 读取，不得硬编码生产 IP。

环境变量缺失时：首页必须继续正常启动；对应卡片显示“暂不可用”，进入按钮禁用或不显示；其他模块入口不受影响；不得抛出未处理异常。

## 7. 响应式规则

- 宽屏：六张核心卡片可多列排列，卡片高度和间距保持整齐。
- 普通笔记本：卡片自动减少列数；标题、状态和按钮不得拥挤或溢出。
- 窄屏：卡片自然换行，主要文本允许换行，不依赖固定像素宽度，不要求横向滚动才能阅读主要信息。

## 8. 后续 UI 开发验收门槛

在进入候选或生产流程前，UI 实现至少要证明：

1. `spread-dashboard` 可以正常启动，六个核心入口全部存在。
2. 现有内部页面与路由继续可访问。
3. USDA 与 Oil World 继续从环境变量读取地址；地址缺失时首页不崩溃。
4. 人工维护数据不显示为自动实时更新；周度数据不因不是当天而误判异常；`partial_failure` 不显示为完整正常。
5. 普通笔记本和窄屏下主要内容不溢出。
6. 既有核心测试、Python 语法检查和 `git diff --check` 通过。
