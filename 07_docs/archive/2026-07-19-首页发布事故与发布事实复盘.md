## 4. 对当前规范的影响

本次复盘已沉淀为以下当前规则：

- 服务器使用独立只读浅克隆，不使用正式仓库作为候选源；
- 复杂 SSH 参数使用固定包装脚本；
- 外层超时大于 Git 内部超时；
- 中文和 Markdown 采用严格 UTF-8 和字节安全传输；
- 验收范围由变更风险驱动；
- 候选结果和证据密封后删除候选容器；
- 正式部署复用候选同一 Image ID；
- `deployment_result.json` 和 Manifest 是当前强制最后阶段；
- 追溯重建必须区分测量值、操作方报告值和不可恢复值。
