## 1. 项目身份

- 项目标识：`agri-dashboard-visual-refresh`
- 项目归属：`spread-dashboard`
- 主要入口：`05_apps/streamlit_app.py`
- 首页实现：`05_apps/home.py`
- 原项目目标：在不改变业务事实、数据口径和应用边界的前提下，将主看板统一为专业、清晰、可扩展的农产品研究工作台。

旧项目说明创建时写为“页面与视觉契约已定义，等待本地 UI 开发”。随后提交 `7f2efc1c240b5b30e8050f9dd6ff2ed50eb54530` 已以 `feat: redesign agricultural research workbench home` 完成相应首页重设计，因此该状态不再是当前事实。

## 2. 当时范围

- 定义首页、侧边栏和模块入口的信息架构；
- 定义首页状态语义、异常提示和外部应用降级；
- 定义共享视觉变量和展示组件边界；
- UI 修改限于 `05_apps/` 展示代码；
- 复用现有数据读取、状态文件和路由；
- 桌面优先，同时支持普通笔记本和窄屏。

## 3. 当时明确非目标

- 不改变价差采集、计算、状态写入或 AKShare 更新；
- 不改变基差和一口价人工 Excel、导入或展示口径；
- 不改变 USDA NASS、美豆周度和外资席位的 Schema、唯一键和业务公式；
- 不新增容器；
- 不改 Docker、Compose、端口、生产挂载、cron 或服务器配置；
- 不复制、合并或重建 USDA 与 Oil World 独立应用；
- 首页不触发更新任务或重新计算数据；
- 不实现最近访问和自定义首页。
