# 新独立服务或重大架构变更模板

> 仅用于确有独立运行、依赖隔离、端口、扩缩容或安全边界需要的事项。普通页面、数据模块和既有应用功能默认使用 [`新功能开发任务模板.md`](新功能开发任务模板.md)，不得借本模板无理由新增容器。

## 1. 立项与必要性

| 项目 | 填写内容 |
|---|---|
| 服务名称 / 业务目标 / 目标用户 | |
| 为什么不能复用 `spread-dashboard`、`usda-dashboard` 或 `oil-world-dashboard` | |
| 依赖冲突、独立扩缩容或安全边界的证据 | |
| 明确不变范围 | |
| 是否已获得新增服务的用户批准 | |

## 4. 使用方法

先提交本模板填妥后的范围卡和证据，再进行架构审计。未证明独立服务必要性时，
停止并回到既有服务内的功能模板；不得预先创建端口、Compose、容器、环境文件或数据目录。
