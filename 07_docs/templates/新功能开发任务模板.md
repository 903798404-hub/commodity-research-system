## 执行与交付记录

- 使用 feature/fix branch；串行任务可复用独立开发检出，并行任务或共享可编辑检出使用独立 worktree；main 镜像不承载开发。可选 `start_project.py --project <id>`。Registry 提供测试映射和责任信息。
- `git fetch origin` / `git ls-remote origin refs/heads/main` 核验远程；填写 base/candidate Commit/Tree。
- 填写相关本地测试、PR 与 exact hosted CI run/attempt；治理变更使用[Maintainer 审查卡](GovernanceTransition.md)。
- main != production；生产单独授权。需要发布时记录风险分类、同一 Image ID、候选与最终页面验收、部署结果和回滚来源。
- 最终填写实际结果、数据/服务器/部署/Git 操作及未解决项。不得用模板中的计划值代替实际通过证据。
