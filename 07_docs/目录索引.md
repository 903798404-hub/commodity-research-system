# 农产品研究 Agent 目录索引

项目顶层目录按照 Python 每日运行顺序排列：先读取数据和配置，再调用核心代码与运行脚本，然后展示网页、输出结果，最后放置文档、测试、部署和日志。

| 目录 | 角色 | 说明 |
|---|---|---|
| `00_项目入口/` | 人工查看入口 | 从这里开始阅读项目 |
| `01_data/` | 数据层 | 原始、人工、中间、处理后和缓存数据 |
| `02_configs/` | 配置层 | 数据源、任务时间、阈值和品种配置 |
| `03_src/` | 核心代码层 | `agri_research_agent` Python 包 |
| `04_scripts/` | 运行入口层 | 命令行入口和轻量调度脚本 |
| `05_apps/` | 网页层 | Streamlit 入口和页面 |
| `06_outputs/` | Agent 输出层 | 日报、Excel、图表和推送日志 |
| `07_docs/` | 中文文档层 | 架构、数据字典和维护说明 |
| `08_tests/` | 测试层 | pytest 自动测试 |
| `09_deploy/` | 部署层 | Docker 与服务器部署说明 |
| `10_logs/` | 日志层 | 程序运行日志 |

## 核心代码

- `03_src/agri_research_agent/core/`：路径、配置、日志和通用结构。
- `03_src/agri_research_agent/data_sources/`：外部及人工数据读取。
- `03_src/agri_research_agent/skills/`：研究 Skill。
- `03_src/agri_research_agent/agents/`：Agent 调度。
- `03_src/agri_research_agent/pipelines/`：正式业务流程。
- `03_src/agri_research_agent/reports/`：报告生成。
- `03_src/agri_research_agent/alerts/`：邮件与飞书推送。
- `03_src/agri_research_agent/utils/`：通用工具。

## 基差数据

- 原始文件：`01_data/manual/basis/国内现货基差.xlsx`
- 标准基差：`01_data/processed/basis_spread/国内现货基差_标准表.csv`
- 标准价差：`01_data/processed/basis_spread/国内现货价差_标准表.csv`
- 标准一口价：`01_data/processed/basis_spread/国内现货一口价_标准表.csv`
- 期货收盘价：`01_data/processed/basis_spread/内盘期货收盘价.csv`

程序不改写原始 Excel。标准 CSV 文件名使用中文，内部字段保持英文。

## 外部应用入口

- USDA 平衡表：独立 React 应用，通过首页外部卡片访问；本地使用方法见 `07_docs/USDA平衡表本地接入说明.md`。

## 外层中文化规则

本项目采用“外层中文，底层英文”：

- 人工查找的文件名、报告名、日志名和页面标题使用中文。
- Python 包名、模块名、函数名、变量名和 CSV 标准字段名保持英文。
- 详细规则见 `07_docs/项目中文化规则.md`。
