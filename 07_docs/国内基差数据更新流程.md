# 国内基差数据更新流程

## 每日使用

1. 更新人工维护文件：`01_data/manual/basis/国内现货基差.xlsx`
2. 在项目根目录运行：

```powershell
python 04_scripts/run_local_dashboard.py
```

脚本会先生成最新的 `01_data/database/basis/basis_quotes.parquet`，打印最新日期、总行数、品种数量和地区数量，然后启动正式面板。

如果数据导入失败，面板不会启动，请根据终端提示检查 Excel。

## 重新打开页面

即使只是重新打开页面，也建议运行同一个脚本，避免读取旧数据：

```powershell
python 04_scripts/run_local_dashboard.py
```

原始 Excel 只由人工维护，程序不会改写。样例数据库仅在正式数据库不存在时回退使用。
