# 农产品研究 Agent 项目中文化规则

本项目采用“外层中文，底层英文”的维护方式。

## 可以使用中文

- 文件夹中供人工查看的文件名、报告名、日志名和页面名尽量使用中文。
- Markdown 日报、Excel 报表、图表输出可以使用中文文件名。
- Streamlit 页面标题和配置文件中的说明文字使用中文。
- 原始 Excel 文件名和 `processed` 标准化输出文件名可以使用中文。

## 必须保持英文

- Python 包名、模块名、类名、函数名、变量名和 import 路径保持英文。
- Python 工程目录及部署引用的路径保持英文。
- 标准 CSV 的字段名保持英文，作为稳定的数据接口。
- 测试文件名以及工具配置键保持英文。

## 数据使用约定

- 原始 Excel 可以使用约定好的中文文件名。
- `processed` 输出文件可以使用中文文件名，但内部字段保持英文。
- Agent 和 Skill 后续只读取约定的标准表，不读取人工随意命名的临时文件。
- `国内现货价差_标准表.csv` 使用中文文件名方便人工查看，内部字段
  `date`、`spread_name`、`spread_value`、`source_sheet` 保持英文。
